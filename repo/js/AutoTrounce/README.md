# 自动征讨领域

## 1. 任务流程

1. 前往征讨领域
2. 根据首领执行不同的前置或后台策略
3. 自动战斗
4. 寻找地脉之花
5. 领取奖励，返回七天神像

## 2. 自定义配置

- 脚本单次只讨伐一个征讨领域。
- 运行前需先选择讨伐目标，填写需要切换到的战斗队伍，以及自动战斗策略。
- 最大重试次数默认为 **3 次**，单轮战斗超时默认为 **180 秒**。
- 脚本不会消耗食物道具或复活料理。如果角色在战斗过程中倒下，会由自动战斗流程处理，传送回七天神像，并开始下一轮尝试。

## 3. 队伍要求

- 多数征讨领域存在必杀机制，建议队伍 DPS 在 **10 万以上**，在触发特殊机制之前完成征讨。
- 部分首领存在瞬移机制，推荐携带具有索敌能力的角色。
- 部分战斗阶段脚本在后台有额外的键鼠输入。为防止转圈，建议将独立任务「自动战斗」的索敌识别间隔适当调高（如 500 毫秒）。
- 讨伐「若陀龙王」建议携带钟离；讨伐「女士」需携带火元素角色；讨伐「正机之神」建议使用高减抗队伍；讨伐「弈局」建议使用冰水元素角色。

## 6. Q&A

**Q：可以同时讨伐多个周本吗？**

A：在配置组中，重复添加该脚本即可。每个任务单独配置战斗队伍和战斗策略。

**Q：如何设置每周运行一次「自动征讨领域」？**

A：前往配置组的设置 → 地图追踪行走配置 → 执行周期配置，开启后设置分界时间为 **4**，周期为 **7**，执行序号为 **5**（周一）即可。

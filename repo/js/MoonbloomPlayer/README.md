# [我不是牌神]月绽放

菈乌玛、哥伦比娅、奈芙尔的七圣召唤 PVE 全自动牌手。自动完成起手换牌、出战、重投、出牌、调和、技能、生成牌选择和阵亡接力，围绕月绽放反应与核输出安排行动。

菈乌玛与哥伦比娅衔接草、水元素反应并布置召唤物，奈芙尔使用诳言之核接力输出。根据敌方附着、血量和当前增益，比较普通攻击、元素战技、元素爆发与核的收益，在反应铺垫、连续输出、爆发和残局补刀之间选择；同时考虑武器、料理、月反应追加效果与充能，安排角色切换和低血量角色的退场接力。

手牌使用结合当前费用、骰色与后续可支付的行动：利用月兆·满辉、困困冥想术等减费，配合「悬木人」、科研的动力和清扫时间补充资源，并安排过牌、白垩之术充能、盈满之实装备及藏锋何处回收转交。生成牌选择结合当前手牌、核、血量和骰子，挑选适合当前局面的选项；每次行动后继续按新的局面调整出牌、调和与技能顺序。

作者：巨鲸也是咸鱼。版本：1.3.0。

## 使用方法

1. 三个角色从左至右依次放置：菈乌玛、哥伦比娅、奈芙尔，并准备下方30张牌。
2. 使用简体中文界面，游戏分辨率保持1920×1080。
3. 停在初始手牌、首次出战或首次掷骰界面启动脚本。请先核对上述角色顺序。
4. 也可以停在新开局、尚未进行任何行动的我方行动页，选择“确认新开局未行动”再启动；不支持恢复已经打了一部分的旧局。
5. 生成牌选择页面自动处理，角色阵亡后选择存活角色继续；核、减费、赋能及随机返骰按实际结果重新决策。
6. 运行期间不要手动点击、出牌或同时运行其他脚本。胜负出现后本次运行结束；需要停止时使用BetterGI的停止功能。

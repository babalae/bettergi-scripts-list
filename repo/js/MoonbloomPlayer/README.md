# [我不是牌神]月绽放

菈乌玛、哥伦比娅、奈芙尔的全自动七圣召唤PVE牌手。自动完成起手置换、出战、重投、出牌、技能、回合推进及阵亡接力，根据实际手牌、骰色、血量和充能调整行动。

作者：巨鲸也是咸鱼。版本：1.2.19。

## 使用方法

1. 三个角色从左至右依次放置：菈乌玛、哥伦比娅、奈芙尔，并准备下方30张牌。
2. 使用简体中文界面，游戏分辨率保持1920×1080。
3. 停在初始手牌、首次出战或首次掷骰界面启动脚本。请先核对上述角色顺序。
4. 也可以停在新开局、尚未进行任何行动的我方行动页，选择“确认新开局未行动”再启动；不支持恢复已经打了一部分的旧局。
5. 生成牌选择页面自动处理，角色阵亡后选择存活角色继续；核、减费、赋能及随机返骰按实际结果重新决策。
6. 运行期间不要手动点击、出牌或同时运行其他脚本。胜负出现后本次运行结束；需要停止时使用BetterGI的停止功能。

适用于普通PVE对局，不保证所有关卡通关。元素免疫、特殊场地及限回合挑战可能需要手动调整牌组或打法；不支持PVP和中途对局接管。

按实际收益选择生成牌，优先保留核的减费与输出资源。特技可用于补刀、过牌护盾或安全接力；鳍游龙的召唤物目标、暝视龙的二次挑选和突角龙的准备普攻暂不主动发动。没有适用效果的生成牌可保留、用于返骰组合或调和，不强行使用。

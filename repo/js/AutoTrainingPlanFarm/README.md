培养计划自动刷取（BetterGI JS 插件）
======================================
一、使用前提
-----------
- BetterGI 0.63.0 及以上
- 游戏内配置好角色培养计划
- 原神简体中文，推荐 1920x1080（已做分辨率自适应，16:9 均可），未测试其它分辨率。可尝试使用
- 仅支持角色天赋书，武器突破材料刷取

二、使用步骤
-----------
1. 添加「培养计划自动刷取」进入配置组，游戏内选择添加培养目标角色，运行「培养计划自动刷取」
2. 自动打开冒险之证 → 秘境 → 提升指南，识别第一行培养标注
3. 逐个点开材料弹窗，读取材料名/来源/培养需求/可合成数量
4. 滑动识别低品质材料，按 3低合1高 精确计算缺口
5. 默认扫描完成后自动刷该行秘境，周末会自动识别，刷对应材料：
6. 刷满该行后自动切换下一行，重新扫描流程
7. 可选择加入日常一条龙，放在每日副本前面，本日无材料脚本自动退出

三、常用设置（不推荐任何修改）
-----------
- runDomain：扫描完自动刷副本（默认开启）
- autoStopWhenEnough：材料齐了自动停
- domainRoundNum：最大秘境轮数，默认 9999（每批在提升指南页 OCR 树脂；缺口>160 树脂耗尽模式，<160 三刷一查、<120 两刷一查、<50 一刷一查；树脂不够 2/3 刷时也走耗尽模式）
- markerThreshold：标注图标阈值，默认 0.9
- autoOpenGuide：自动打开提升指南页
- debugShowBoxes：调试识别框开关（默认关闭，开启后在游戏画面上显示识别框）
- partyName：队伍名称，留空用 BGI 本体设置，建议配置BGI独立任务中的队伍名称
- sundaySelectedValue：周日/限时全开领奖序号兜底

四、注意事项
-----------
- 树脂耗尽模式（本批树脂不够 2/3 刷时自动启用）刷取结束后，插件会直接完成整个流程
- 无操作 8 秒自动退出
- 奖励识别失败时会自动回冒险之证刷新

五、资源说明
----------
- assets/RecognitionObject/guide_marker_green.png：培养计划标注图标的模板图片，用于模板匹配扫描每行材料标注
- assets/debug_boxes.html：调试识别框遮罩页面，仅 debugShowBoxes=true 时加载

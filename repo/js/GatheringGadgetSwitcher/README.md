# 采集小道具切换

从背包小道具页自动查找并装备以下道具：

- `化种匣`：适合放在可采种植物路线之前。
- `王树瑞佑`：适合放在自动伐木脚本之前。

脚本只负责装备切换，植物采集路线与伐木任务继续由对应脚本执行。当前装备已经符合配置时，脚本识别到“卸下”按钮后直接结束。

## 使用方法

1. 将脚本加入调度器配置组。
2. 右键打开“JS 脚本自定义配置”。
3. 选择 `化种匣` 或 `王树瑞佑`。
4. 将脚本放在对应采集任务之前。

示例编排：

```text
采集小道具切换（化种匣）
植物采集路线
采集小道具切换（王树瑞佑）
自动伐木-地图追踪版
```

## 使用条件

- 账号已经获得所选小道具。
- 从游戏主界面启动。
- 已在 BetterGI `0.64.0`、游戏 `1920×1080` 环境实机验证。

## 实机验证

- 化种匣能够识别“已装备”和“替换”状态；装备后，甜甜花路线连续识别到“甜甜花的种子”。
- 王树瑞佑能够从化种匣切换成功；后续社区伐木脚本识别到王树瑞佑，并完成一轮桦木路线，记录获得桦木 75。

## 资源说明

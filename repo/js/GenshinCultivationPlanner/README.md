# 角色一键养成

选好角色、天赋和武器的培养目标后，脚本会读取背包，扣除已有材料和可通过 3:1 合成得到的数量，再安排从今天开始的一周刷取计划。当天能刷的培养秘境、世界 Boss、圣遗物秘境和已订阅路线，可以直接交给 BetterGI 执行。

运行结束后，日志和邮件会列出本次确认获得的材料、当前缺口，以及培养秘境或 Boss 大约还要领取多少次奖励。收益通常以运行前后的背包差值为准；结束背包漏识别时，会使用 BetterGI 已识别到的任务奖励兜底。脚本不会替你点击升级；这里的“一键”是把材料计算、每周规划、任务调度和结果统计放进一次运行。

## 它会帮你做什么

- 按角色、三项天赋和武器的目标等级计算材料需求，不用逐级查表。
- 扣除背包库存，并沿合成链统一计算天赋书、武器突破材料和怪物材料；展示时仍按高、中、低阶分别列出。
- 按秘境开放日生成七天循环计划，周日会自动选择对应材料系列。
- 自动匹配所需世界 Boss，不要求手写 Boss 名称。机制特殊的 Boss 可以从下拉框选择专属队伍、策略或单独禁用。
- 调用 BetterGI 的秘境、自动首领和 AutoPathing 能力执行当天任务，并用运行前后的背包差值统计收益。

## 使用前准备

1. 使用 BetterGI `0.63.0` 或更高版本，并在 BetterGI 设置中选择 OCR V6。
2. 如果要刷地方特产或怪物材料，先在 BetterGI 中订阅对应的 AutoPathing 路线。
3. 准备好任务队伍。配置中的队伍名称必须与游戏内完全一致。

角色、武器或背包数量文字识别异常时，先确认 OCR V6 已启用，再重新运行。背包中的物品名称由 BetterGI ItemV2 图标模型匹配，并不使用 OCR；日志会把“图标未匹配”和“数量 OCR 失败”分开提示。脚本无法读取或切换 BetterGI 当前使用的 OCR 版本。

## 配置与运行

1. 在 BetterGI 脚本仓库中订阅并添加“角色一键养成”。
2. 选择角色、目标等级和三项天赋；需要培养武器时，再选择武器和目标等级。
3. 填写培养秘境队伍。世界 Boss、地方特产、怪物路线和圣遗物填充默认关闭，需要时再开启并填写对应队伍。
4. 检查配置，勾选设置页顶部的“我已确认配置并允许实际执行”，然后运行脚本。未勾选时脚本会立即结束，不读背包、不写记录、不发送通知，也不操作游戏。

世界 Boss 会根据缺少的突破材料自动匹配。通用队伍无法处理某个 Boss 时，可以使用三个“专属配置”槽：Boss 名称从按地区分组的列表中选择，队伍和策略留空则继承通用配置。“禁用”会跳过该 Boss，继续寻找当天可执行的培养秘境。

多个目标或下拉框未覆盖的特殊区间可以启用“自定义培养目标”：

```text
申鹤:70>90,6/8/8>9/9/9；和璞鸢:70>90
```

中文和英文的分号、逗号、冒号都可以使用，也可以换行分隔。启用自定义目标后，上方的角色、武器、等级和天赋选项不再生效。

## 调度规则

树脂任务使用固定顺序：世界 Boss → 当天开放的限时培养秘境 → 普通培养秘境 → 圣遗物秘境填充。一次运行只执行第一个已启用且可以执行的树脂任务，不会在多个秘境之间拆分树脂。树脂任务结束后，再执行已开启的地方特产和怪物路线。

圣遗物填充默认关闭。启用后，只有当天没有可执行的 Boss 或培养材料秘境时才会加入队列。它支持单次和正式模式、独立队伍与独立战斗策略；不会自动分解圣遗物，也不会把圣遗物计入培养材料收益或预计完成天数。

培养秘境和圣遗物秘境默认先用已有的浓缩树脂，再用原粹树脂；高级设置可以选择其他树脂组合。脚本不会制作浓缩树脂，世界 Boss 只使用原粹树脂。正式模式会尽量用完所选树脂，可能比当前缺口多刷少量材料。

秘境和世界 Boss 默认启用 BetterGI 的任务级奖励识别，便于在日志中查看每轮掉落。背包仍只在所有任务开始前和结束后各读取一次：背包差值可信时优先采用；结束背包漏识别时，任务奖励作为兜底，两者不会重复相加。最新计划和最近 100 次运行记录保存在脚本目录中；如果订阅了 BetterGI 的 `js.custom` 通知，还可以收到排版后的运行摘要。

周本材料会计入需求，但 0.9.0 不自动打周本。它们会单独列在“需手动获取”中，也不会挡住 Boss、秘境或路线任务。

## 路线匹配

脚本不附带 AutoPathing 路线，也不会联网下载。常见订阅目录如下：

```text
地方特产/国家/材料名/**/*.json
敌人与魔物/怪物名/**/*.json
```

脚本会按材料名和常见别名查找路线。没有匹配到时，可以在 `data/route-overrides.json` 中指定路径。刷蕈兽孢子时请准备不使用火、雷攻击的队伍，否则掉落会发生变化。

## 当前边界

- 不执行角色或武器升级，不刷摩拉、经验书和元素突破玉，也不执行材料合成。
- Boss、路线和圣遗物填充默认关闭。实际战斗和路线稳定性取决于 BetterGI 版本、队伍与订阅路线质量。
- 背包差值和任务奖励都没有确认到目标材料时，摘要会写“未确认”，不会把“任务已调用”当成“奖励已领取”。ItemV2 图标未匹配时优先检查 BetterGI 版本；数量文字异常时再检查 OCR V6。
- 第一次切换任务队伍前会先传送到七天神像；后续切换失败时只传送并重试一次，避免错误队伍名造成循环。
- 自动读取角色当前档案、当前佩戴武器、复杂树脂调度和周本自动执行不在 0.9.0 中。

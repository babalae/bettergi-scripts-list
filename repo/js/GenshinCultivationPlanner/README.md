# 角色一键养成

选好角色、目标等级和天赋，脚本会读取当前进度，计算还缺哪些材料、各缺多少，再匹配世界Boss、培养秘境和本机已订阅路线。结束邮件会列出刷取结果、剩余材料与后续计划，不用翻日志也能了解培养进度。

武器可以读取当前佩戴的，也可以手动指定或不培养。材料计算会扣除背包库存，并按同系列3:1合成关系抵扣缺口；不计入角色天赋的随机返还或额外产出，也不会替你升级或合成。

## 使用前准备

- **BetterGI 0.66.0或更高版本，开启OCR V6**；更早版本不支持。文字识别异常时先检查OCR设置。
- 使用简体中文。读取角色圣遗物推荐需要1920×1080、16:9与默认界面缩放。
- 配置对应队伍与战斗策略。策略留空时沿用BetterGI对应任务的全局配置。
- 采集和怪物材料需要先订阅地图追踪路线，脚本不会自动下载路线。
- 想收邮件，请在BetterGI配置邮箱并订阅`js.custom`。

## 开始培养

1. 用途选“正常培养”，选择角色和培养内容。
2. 设置角色目标等级、三项天赋，以及可选的武器。
3. 配置并启用需要的秘境、Boss、采集或怪物路线。Boss、路线和圣遗物填充默认关闭。
4. 勾选顶部“允许实际执行”，从调度器运行。不要求首次使用额外进行单次测试。

未确认时立即结束，不读取背包、不写记录、不发送通知，也不操作游戏。预览模式只生成目标，不刷取。

**等级未标注已突破时按突破前计算。**手动`80>90`表示从80/80开始，`80后>90`表示从80/90开始；自动档案使用实际等级与上限，不靠等级数字猜突破状态。

需要多个目标时，可启用自定义目标，例如：`申鹤:80>90,6/8/8>9/9/9；和璞鸢:80后>90`。启用后，上方角色、武器和等级选择不再用于生成目标；队伍、树脂和执行开关仍生效。

## 刷取安排

默认优先角色和武器等级，再刷天赋：**角色突破Boss → 武器突破秘境 → 天赋秘境 → 圣遗物填充**。培养秘境按开放日安排，周日选择对应材料。默认只执行首个可用树脂任务，之后运行已启用的路线；高级设置可调整顺序和领奖上限，不在多个同类秘境间精确分配树脂。

默认先浓缩、后原粹。须臾和脆弱树脂只有主动授权才使用，不制作浓缩树脂。世界等级9的Boss还会按缺口限制领奖次数，并与用户上限取较小值；实际掉落可能造成少量溢出。

路线在`User/AutoPathing`中按材料名与别名匹配。同材料多个作者版本只选一套，分段依次执行；不能保证不同JSON的点位完全不重叠。需要固定路线时，可在`data/route-overrides.json`指定相对路径或本机绝对路径。

不支持的Boss提示手动获取。已知战斗或领奖失败后，只有确认安全退场才继续路线；取消、退场失败或未知异常会停止后续游戏操作。特殊机制仍需要合适队伍。

## 按角色刷圣遗物

用途选“仅刷角色圣遗物”，选择角色即可。默认读取游戏提升指南的**第一项四件套推荐**，匹配秘境，复用圣遗物队伍、策略与树脂配置；也可从下拉框手动指定套装。

正常培养中也可启用“无培养任务时按角色填充”：当天没有可执行培养树脂任务时，再刷角色推荐套装。不开新开关，原手动圣遗物填充保持不变。

两件加两件、推荐不完整或前后不一致、套装没有受支持秘境时，不猜测、不沿用旧推荐。第一项不代表所有玩法唯一最优。**当前不扫描词条、不评分、不判断毕业或达标停刷，也不锁定、强化、分解或装备圣遗物。**

## 进度与邮件

培养模式整次运行只在开始、结束各读取一次目标材料背包。可信背包差值优先，任务奖励可兜底，两者不相加。开始数量未知时，不把结束库存全部当作新收益；结束库存可信时仍可显示剩余缺口或已足够。

每个配置组只发结束摘要，异常时发失败摘要；超过500字符则编号分封，保留完整材料明细。独立配置组各有自己的邮件。圣遗物奖励单独列出，不纳入培养材料收益；缺少证据时显示领奖未确认，不直接猜测树脂不足。

计划与最近100次记录保存在`record/`。预计进度仅供参考，周本、圣遗物和路线不显示完成天数。

## 功能边界

不升级角色、武器或天赋，不合成材料；不刷摩拉、经验书和元素突破玉。周本材料只计算提醒，需手动获取。战斗、传送、树脂识别与路线追踪由BetterGI执行；独立配置组没有可靠树脂余额共享，树脂用尽后，后续原生任务仍可能开战才退出。

提升指南批量培养目标、路线订阅助手和圣遗物评分研究不在本公开版中。

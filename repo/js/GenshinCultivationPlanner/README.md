# 角色一键养成

选好角色和培养目标后，脚本会读取背包，扣除已有材料和可通过 3:1 合成得到的数量，再安排从今天开始的一周刷取计划。当天能刷的秘境、世界 Boss 和已订阅路线，可以直接交给 BetterGI 执行。

一次运行结束后，日志和邮件会告诉你这次获得了什么、还缺什么，以及培养秘境或 Boss 大约还要刷几次。脚本不会替你升级角色或武器；这里的“一键”指一次完成材料计算、规划和刷取调度。

## 这个脚本适合做什么

- 只填培养目标，不必自己查每一级需要多少材料，也不用手算背包差额。
- 天赋书、武器突破材料和怪物材料会沿合成链统一计算，但结果仍按高、中、低阶分别列出，方便核对。
- 限时秘境按开放日安排，除了今天的任务，还会给出接下来七天的循环计划。
- 秘境、世界 Boss 和路线由 BetterGI 现有能力执行；脚本负责决定该刷什么、按什么顺序刷，并记录前后两次背包差值。
- BetterGI 0.63.0 及以上可以使用“自动档案”：只选角色和目标等级，脚本读取当前角色等级、天赋与佩戴武器。旧版本继续使用完整的手动档案。

## 第一次使用

1. 在 BetterGI 脚本仓库订阅并添加“角色一键养成”。
2. 选择档案模式。手动档案需要填写当前等级和目标等级；自动档案只填写角色、角色目标、三项天赋目标和佩戴武器目标。自动档案需要 BetterGI 0.63.0 及以上。
3. 填写任务会用到的队伍名称，文字必须和游戏内队伍名完全一致。
4. 培养秘境默认正式运行；如果还要自动刷世界 Boss、地方特产或怪物材料，请开启对应任务并填写队伍。
5. 检查配置，勾选“我已确认配置并允许实际执行”，然后运行脚本。未勾选时脚本会立即结束，不读背包，也不会操作游戏。

自定义目标可以这样写：

```text
申鹤:70>90,6/8/8>9/9/9；和璞鸢:70>90
```

中文和英文的分号、逗号、冒号都可以使用，也可以换行分隔。启用自定义目标后，上方的角色、武器、等级和天赋选项不再生效。

## 脚本会怎样安排任务

默认顺序是：世界 Boss → 当天开放的限时培养秘境 → 普通培养秘境 → 圣遗物秘境填充。脚本会依次检查当天的候选任务；未启用的任务直接跳过，配置、切队或执行失败时停止后续树脂任务。地方特产和怪物路线默认放在树脂任务之后，也可以改到前面。脚本不会在多个秘境之间精确拆分树脂。

培养秘境和圣遗物秘境默认先用已有的浓缩树脂，再用原粹树脂；须臾和脆弱树脂有各自的授权开关，默认关闭。高级设置还可以调整任务顺序、原粹树脂预算与保留量、每类任务上限和圣遗物填充条件。运行日志会先打印解析后的规则，`tools/preview-execution-policy.mjs` 也能在不启动游戏时检查配置。脚本不会制作浓缩树脂，世界 Boss 只使用原粹树脂。

背包只在所有任务开始前和结束后各读取一次。本次收益以这两次的库存差值为准，不会在每次领奖或每条路线结束后反复打开背包。最新计划和最近 100 次运行记录会保存在脚本目录中；如果订阅了 BetterGI 的 `js.custom` 通知，还可以收到排版后的运行摘要。

周本材料也会计入总需求，但 0.9.0 不自动打周本。它们会单独列在“需手动获取”中，也不会挡住当天的 Boss、秘境或路线任务。

## 路线怎么匹配

脚本本身不附带 AutoPathing 路线，也不会联网下载。请先在 BetterGI 中订阅需要的地方特产和怪物路线，常见目录结构是：

```text
地方特产/国家/材料名/**/*.json
敌人与魔物/怪物名/**/*.json
```

脚本会按材料名和常见别名查找路线。没有匹配到时，可以在 `data/route-overrides.json` 中填写单个 JSON、多个 JSON 或一个目录；目录会递归展开。覆盖项也能指定专属队伍、记录所需角色，或者单独禁用某种材料的路线。刷蕈兽孢子时请准备不使用火、雷攻击的队伍，否则掉落会发生变化。

```json
{
  "101215": {
    "paths": ["地方特产/须弥/月莲"],
    "type": "localSpecialty",
    "partyName": "采集队",
    "requiredCharacters": ["纳西妲"],
    "enabled": true
  }
}
```

路线收益只采用整次运行前后的真实背包差值。相同 JSON 文件集合积累至少两次正收益后，脚本会估算还需跑几轮；路线文件变化、收益为零或识别未确认时不沿用旧数据，也不换算自然日。

## 使用前需要知道

- 摩拉、经验书和元素突破玉不在自动刷取范围内，脚本也不会执行材料合成。
- 每类任务的次数是授权上限，不是精确完成值。脚本不会在每次领奖后打开背包，因此可能多刷少量材料。
- Boss、秘境和路线能否稳定完成，取决于 BetterGI 版本、队伍和路线质量。Boss 与路线默认关闭，开启前请确认队伍和已订阅路线能够处理对应任务。
- 背包 OCR 可能失败。没有确认到数量增长时，摘要会写“未确认”，不会把任务已经调用当作奖励已经领取。
- 圣遗物秘境填充不会自动分解圣遗物，也不会把圣遗物计入养成材料收益。
- 第一次切换任务队伍前会先传送到七天神像。后续切换失败时只传送并重试一次，避免队伍名写错后一直循环。
- 自动档案接口来自 BetterGI 0.63.0。该版本发布说明提到识图底层重构后可能有未知问题；本项目已完成接口模拟测试，游戏内识别仍待集中回归。识别字段为空、武器未知或接口缺失时会在读取背包前停止，不会套用默认等级。

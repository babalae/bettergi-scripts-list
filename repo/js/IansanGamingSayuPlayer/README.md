# [我不是牌神]伊安珊嘉明早柚[进阶]

**七圣召唤PVE自动打牌脚本。** 让伊安珊、嘉明和早柚组成接力队伍，根据当前手牌、骰子、角色状态和敌方元素附着安排行动，而不是固定按顺序释放技能。支持起手换牌、装备与行动牌的使用、调和补骰、元素反应配合，以及角色阵亡后的换人接力。

作者：巨鲸也是咸鱼。版本：**0.1.9**。适用于七圣召唤PVE对局。

## 使用方法

1. 使用 BetterGI **0.66.0或更新版本**，游戏语言设为**简体中文**，实际游戏画面为 **1920×1080**。
2. 按下方推荐牌表配牌。角色从左到右必须是 **伊安珊 → 嘉明 → 早柚**。首发角色由脚本根据开局情况选择。
3. 导入脚本，在 BetterGI 调度器中添加本脚本。手动安装时，将 `IansanGamingSayuPlayer` 文件夹放入 `User/JsScript/`，刷新脚本列表。
4. 手动进入新对局，停在**初始手牌、首次选择出战角色、首次掷骰**中的任意页面，启动脚本。先选人或先掷骰的对局都可以使用。

**不要从行动页或中途对局启动。** 脚本只自动打当前一局，下一局仍需手动进入后再启动。需要中止时使用 BetterGI 的停止按钮或停止热键。

自定义配置只有两项：

- **初始手牌**：默认“优先装备与启动牌”，根据起手组合置换；同名武器只留一张，运筹帷幄可留两张。也可选择“全部保留”。
- **单局超时保护**：默认15分钟，可选10或20分钟。

## 缺牌与换牌

**不要求先集齐推荐牌组。** 缺牌时可以先用已有牌按游戏组牌规则填满30张，之后逐步替换。

另外支持甜甜花酿鸡、蒙德土豆饼、莲花酥、最好的伙伴！、交给我吧！、本大爷还没有输！、星天之兆、白缨枪、铁影阔剑。未支持的牌不会主动打出，可靠识别到牌名后可以用作元素调和。不需要切换牌组模式。

## 战术解说

前台日志会简要说明当前行动的目的，例如：

```text
[开局] 伊安珊先行动，尝试挂雷后再接力。
[第1回合] 准备切换早柚，计划接战技，敌方已有雷附着，接续扩散，接续准备技能风风轮舞踢。
[第2回合] 早柚仅剩1点生命，准备切换伊安珊，计划接战技，尝试挂雷，为快速切换接力做准备。
[第2回合] 早柚准备进行普通攻击，敌方出战剩5点生命，按当前伤害估计尝试主动补刀。
[第2回合] 为早柚大招补风骰：调和「黄金屋」。
[第2回合] 骰子与充能满足，早柚准备释放元素爆发，布置不倒貉貉，等待结束阶段伤害与治疗。
[调整] 手牌发生变化，重新同步后继续。
[接力] 早柚已阵亡，准备切换嘉明继续作战。
```

日志会说明切人的后续计划、嘉明回场接力、调和目标和预计补刀。“后续计划尝试收尾”指连续行动计划，脚本会在每步结算后按实际牌面调整。

战术解说中的伤害与补刀是估计，胜负以实际结果页为准。

如果遇到停止，请查看 BetterGI 日志及脚本目录的 `logs/`。分享日志和截图前请检查玩家名称、UID等个人信息，不要直接公开整个日志目录。

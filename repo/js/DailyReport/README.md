# 每日日报

识别每日委托状态、树脂数量、原石数量、历练点，并支持多账号缓存与总览。

## 功能

| 项目 | 说明 |
|------|------|
| 每日委托 | 识别奖励是否已领取（含进度 x/4） |
| 原粹树脂 | 多位数模板优先，OCR 兜底 |
| 浓缩树脂 | 数字模板（0~5）优先，OCR 兜底 |
| 须臾树脂 | OCR 优先，失败用数字模板（1~4）兜底；识别剩余天数 |
| 脆弱树脂 | OCR 识别 |
| 原石 | OCR 识别，不设上限 |
| 历练点 | OCR 识别 |
| UID 识别/校验 | 可选，防止跑错账号 |
| 账号缓存 | 按账号名写入缓存，支持总览模式汇总 |

## 配置选项

| 选项 | 说明 |
|------|------|
| 识别树脂 | 开启树脂/原石识别（实验性） |
| 调试模式 | 输出原始 OCR 文本、识别区域框等调试信息 |
| 账号备注名 | 缓存的总开关，为空则不启用缓存 |
| 识别UID | 读取当前账号 UID |
| 校验UID | 与期望 UID 对比，不一致则不写入缓存 |
| 期望UID | 校验时填写的目标 UID |
| 总览模式 | 仅读取缓存生成汇总通知，不执行游戏操作 |

## 缓存结构

缓存文件为脚本目录下的 `account_cache.json`，每个账号一条记录：

```json
{
  "账号备注名": {
    "commission": "每日委托奖励已领取",
    "resin": "原粹:10 浓缩:5 须臾:1(9天) 脆弱:41",
    "primogem": 26640,
    "encounter": "历练点:32.2",
    "uid": "123456789",
    "time": "2026/10/31 02:16:31"
  }
}
```

- 委托与树脂数据按每日 4:00 刷新周期标记是否过期，过期数据在总览中视为不可信
- 历练点数据不检查过期时间，直接使用缓存值进行报警

## 总览模式

开启总览模式后，脚本不操作游戏，直接读取缓存并发送汇总通知：

- 委托总览：已领取 / 未领取 / 未完成的账号（过期数据视为不可信）
- 体力总览：原粹树脂低于阈值（20）的账号（过期数据视为不可信）
- 历练点提醒：低于 12 的账号，低于 4 额外提示不足以完成委托（不检查数据过期时间）

## 坐标体系

所有识别区域使用 1080P 基准坐标，运行时通过 `scaleTo1080PRatio` 自动适配实际分辨率。

# 素材来源与署名

部分骰子、手牌数量、角色状态、充能及行动标记模板参考或取自 [DSTCG（牌圣）](https://github.com/babalae/bettergi-scripts-list/tree/main/repo/js/DSTCG)，原作者：提瓦特钓鱼玳师 / Hijiwos。来源路径为 `repo/js/DSTCG/assets`，参考提交为 `500f2a6ec564bc5f008594fb68cb8c1ae51eb58c`。

`assets/core/` 的按钮与限制状态模板取自 [BetterGI 0.66.0](https://github.com/babalae/better-genshin-impact) 的 `GameTask/AutoGeniusInvokation/Assets/1920x1080/other`。其 GPL-3.0 许可正文保留在 [LICENSE-GPL-3.0.txt](LICENSE-GPL-3.0.txt)。

手牌边缘、空手区域、激化领域及次数等补充模板由原生游戏画面裁剪。其中空手模板来源于伊嘉早自动牌手。

本脚本的规则、策略及交互代码由本脚本实现，参考了已有脚本及 BetterGI 的布局和接口。

# [我不是牌神]雷神柯莱刻晴

**七圣召唤 PVE 全自动打牌脚本。** 手动进入对局并启动后，自动处理选人、重投骰子、出牌、装备、料理、元素调和、切换角色、释放技能和结束回合。角色阵亡后会自动选择存活角色继续战斗，无需手动逐张出牌或点击技能。

作者：巨鲸也是咸鱼。版本：0.4.6（测试版）。

## 使用方法

1. 使用 BetterGI **0.66.0 或更新版本**，游戏语言设为**简体中文**，实际游戏画面为 **1920×1080**。
2. 按下方任意一套牌表配牌。角色从左到右必须是 **雷电将军 → 柯莱 → 刻晴**，开局由脚本选择雷电将军出战。
3. 订阅并导入脚本，在 BetterGI 调度器中添加本脚本，打开 **JS 自定义配置**，把“模式”改为 **“自动试验”**；默认“识别诊断”只检查画面，不会自动打牌。“对方角色总数”填写这场对局的敌方角色数量，包含已经阵亡的角色。
4. 手动进入对局，停在**初始手牌、首次选择出战角色、首次掷骰**中的任意页面，启动脚本。先选人或先掷骰的对局都可以使用。

如果已经刚进入行动页，仍可启动：先把“行动页启动”设为 **“确认新开局未行动”**，并确保双方都还没有出牌、放技能、切人或调和。中途已经行动过的对局不支持重新接管。

“初始手牌”可选“全部保留”或“优先充能与调骰”。单局时限默认 15 分钟，较长的对局可以改为 20 分钟。需要中止时使用 BetterGI 的停止按钮或停止热键。脚本只自动打当前一局，下一局仍需手动进入后再启动。

## 缺牌与换牌

两套牌组使用**同一个脚本**，不需要切换牌组模式，也不要求先集齐完全版。缺牌时先用已有牌填满 30 张，之后逐步替换即可；未支持的牌不会主动打出，识别到后可以用作元素调和。

雷楔由刻晴战技生成；碎霆、锐核由雷草祝佑产生，**不需要额外加入牌组**，选牌及后续使用由脚本处理。

当前为测试版。遇到识别异常导致停止时，可查看 BetterGI 日志和脚本目录的 `logs/`；分享截图前请检查个人信息。素材来源与署名见 [ATTRIBUTION.md](ATTRIBUTION.md)。

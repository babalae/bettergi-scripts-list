# [我不是牌神]雷神柯莱刻晴

作者：巨鲸也是咸鱼。版本：0.4.6（测试版）。

给雷电将军、柯莱、刻晴使用的七圣召唤 PVE 自动牌手。不是固定放技能：会读取手牌、骰子、血量和充能，选择出牌、元素调和、切人、技能或结束回合。支持雷楔、装备与料理，以及雷草祝佑的选牌和衍生牌流程。角色阵亡时重新选择存活角色，继续当前对局。

## 使用方法

1. 使用 BetterGI **0.66.0 或更新版本**，游戏语言为简体中文，实际游戏捕获区域为 **1920×1080**。脚本不会替你修改游戏分辨率。
2. 角色从左到右排列为 **雷电将军 → 柯莱 → 刻晴**；开局默认选择雷电将军。两套参考牌组见下表，不必集齐才能启动。
3. 手动进入对局，在**初始手牌、首次选择出战角色、首次掷骰**中的任一页面启动。先选人或先掷骰都可以。
4. 在 JS 自定义配置中，首次可以用默认的“识别诊断”检查状态；要自动打牌，改为 **“自动试验”**。“对方角色总数”填写包含已阵亡角色的总数；识别到明确的原生角色槽位时以实际布局为准。
5. 也可以在刚进入的行动页启动，但须选择 **“确认新开局未行动”**，且双方都尚未出牌、放技能、切人或调和。不能用它恢复中途退出的对局。

“全部保留”是默认起手设置；“优先充能与调骰”会尝试按可靠卡名换牌，读不清时保留。脚本只打当前一局，不会自动找 NPC、领奖或连续开局。需要中止时用 BetterGI 的停止按钮或停止热键。

## 牌组：新手版与完全版

两套均使用相同角色。**新手版对应早期旧牌组，完全版对应后续预设计的雷草祝佑新牌组**，是同一个脚本的两种参考构筑，不是两份不同程序，也不需要切换牌组模式。

新手版主要靠雷神启动、柯莱接力、刻晴收割，牌型较少；完全版加入雷草祝佑、赦免宣告、流放者头冠、刻晴天赋等，减少部分料理，为大招链、调骰和阵亡后的续战留位置。这里的“完全版”指参考构筑，不代表所有游戏机制都已实现。

缺牌时可以用已拥有的牌填满 30 张，之后逐步替换成完全版。脚本按实际手牌运行，缺少充能、装备或祝佑不会成为启动门槛；未支持的牌不会盲目打出，可靠识别后可以作为调和材料。也支持白缨枪、鸦羽弓、旅行剑等基础武器替换，但任意新卡引入的交互不保证都能处理。

## 策略与读牌

雷神优先启动与补充后台充能，柯莱衔接草伤，刻晴负责后续输出；实际动作会结合血量、充能、骰子、剩余手牌和可达后续行动选择，不固定“一直站刻晴”。大招前可以调和低价值牌；雷楔可以用于切换并释放刻晴战技。一掷乾坤走战中重投流程，不把它当成新回合掷骰。

手牌使用缓存：普通技能、切人不重新检视整手；确认出牌或调和后删除对应位置。新回合、抽牌、生成牌或发现数量/身份不符时才重新读牌。完整检视一次展开、逐张读取、最后归位；1–4 张按真实展开布局计数，不点击猜测的空位。

## 已测试与限制

0.4.6 在卡瑟莉亚“安全运输法则”完成两场无人补出牌的自动胜利，均达成 3/3 目标；两局分别约 7 分 10 秒、5 分 22 秒。实际取得 1、2、3、4 张原生展开画面，并验证低张数出牌与调和。这个样本不能当作胜率统计或所有 NPC 均可通关的保证。

随包提供 358 项规则/宿主测试和 31 项策略测试，包括缺牌组合、资源支付、开局顺序、阵亡切人和特殊交互的合成回放。测试用 Node.js 18+ 执行，不需要连接游戏：

```sh
node tests/run.cjs
node tests/strategy.cjs
```

脚本不是完整七圣召唤规则模拟器：对手手牌、支援/召唤区与所有场地效果没有完整建模。遇到持续读不清的状态或未支持的交互会保护停止。阵亡换人和无计数战中重投有代码/回放覆盖，但未在上述两场 0.4.6 胜局中触发。

运行只使用 BetterGI 本地截图、OCR 和输入接口，**不接入 LLM、不需要 API Key、没有网络请求**。会在脚本目录的 `logs/` 保存诊断日志及部分识别截图；反馈问题前请自行检查截图中的昵称等个人信息。模板来源和许可记录见 [ATTRIBUTION.md](ATTRIBUTION.md)。

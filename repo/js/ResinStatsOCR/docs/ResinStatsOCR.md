# ResinStatsOCR 实现说明

> 随包分发的实现文档。用法见 `../README.md`，本文讲结构、判据与约束。
> 版本 v6.5 · 2026-11-05

## 运行前提

| 项 | 要求 |
|---|---|
| 分辨率 | 16:9，≥1920×1080（低于 1600×900 部分功能异常） |
| 截图坐标系 | ≤1920×1080；更高时自动缩放到 1920×1080 |
| JS 通知权限 | 调度器通用设置里勾选，否则通知被拦，脚本侧无法自救 |
| 游戏状态 | 能回主界面 |

声明 1920×1080 只是脚本环境，BGI 按实际窗口自动适配，不是锁成固定分辨率。

## 结构

三个文件单向依赖：入口 → 流程与识别 → 常量与纯函数。根目录只放入口与配置，代码模块在 `src/`，图标在 `assets/resin/`（路径按脚本根算，不与复用方自己的 `assets/icon/` 混放）。

流程层对外只有一个入口，返回：

```js
{ ok, uid, requested, resin, transientDays, steps, error?, errorStack? }
```

- `resin` 与 `requested` 各四项（原粹、浓缩、须臾、脆弱）。读不到与未请求都是 `null`，用 `requested` 区分
- `steps` 为 `true`（走通）/ `false`（试过失败）/ `"skip"`（按开关没走）
- 不抛异常：开页或点「+」失败返回 `ok:false` + `error`，已读到的项照常带回

### 读数开关

入口接收开关数组，顺序固定 `[原粹, 浓缩, 须臾, 脆弱]`，不传 = 全读，短数组补 `false`。

```
needDialog = 须臾 || 脆弱                  → 点「+」、进弹窗
needPage   = 原粹 || 浓缩 || needDialog    → 进秘境页
```

只读须臾/脆弱时跳过秘境页读数，但秘境页与「+」仍要走（弹窗从那一页点开）；全 false 时连游戏界面都不碰。原粹兜底只在进弹窗时才有，没进弹窗时读不到就只能是「未知」。

### 作为库调用

把 `src/` 的 `resin.js`、`utils.js` 两个文件**放同一目录**拷过去（示例目录叫 `resinReader`，换了名要同步改 import），再把 `assets/resin/`（14 张 PNG）拷到调用方脚本根下。入口只有一个函数：

```js
import { collectResin } from "./resinReader/resin.js";
const r = await collectResin([true, false, false, false]);
```

- 入参 `flags`：四位布尔，顺序固定 `[原粹, 浓缩, 须臾, 脆弱]`，开关怎么裁剪界面步骤见上文「读数开关」；不传 = 全读，短数组按 false 补齐，不是数组按全读处理并记警告
- 返回值 await 之后是一个对象，失败也一样，先判 `ok`：
  - `ok`：流程没走通（开不了秘境页 / 点不了「+」）为 `false`，`error` 带原因、`errorStack` 带堆栈；已读到的项照常在 `resin` 里
  - `resin` / `requested`：各四键 `original` / `condensed` / `transient` / `fragile`（原粹 / 浓缩 / 须臾 / 脆弱），数字或 `null`；没请求与没读到都是 `null`，靠 `requested` 区分
  - `uid`：字符串或 `null`，只在真进了游戏界面时才有机会读到
  - `transientDays`：数字或 `null`，须臾剩余天数，没请求须臾恒为 `null`
  - `steps`：三键 `openSecret` / `clickPlus` / `dialogClosed`，`true` 走通 / `false` 试过失败 / `"skip"` 按开关没走；只记界面三步，不含读数
  - 四位全 false：不碰游戏界面，`ok` 仍为 `true`，但 `uid` 与四项全是 `null`
- 图标路径按**执行脚本的根目录**解析，不认模块位置
- 释放、回主界面、多次调用的排队都由入口内部处理，不要指望并发提速
- 代价是每次调用重读一遍图标，量级可忽略

## 流程

| 步 | 做什么 | 失败 |
|---|---|---|
| ① | 开冒险手册，点左侧「秘境」 | 中止，`ok:false` |
| ② | 秘境页读原粹 + 浓缩 | 单项未知，继续 |
| ③ | 点原粹旁的「+」 | 中止，`ok:false` |
| ④ | 弹窗读须臾 + 脆弱 | 单项未知，继续 |
| 退出 | ESC 关弹窗 | 无 |
| 收尾 | 释放资源 + 回主界面（没进过界面就跳过） | 记日志，不改返回值 |

全程不写死坐标：定位靠「比例区域 + OCR 文本 + 模板匹配」，点击一律走识别出的区域中心。

## 判据

### ① 秘境页

- 开手册三条路：F1 → ESC 菜单点「冒险之证」→ 再 F1 一次
- 「已开」判据：左侧标签列命中「见闻 / 委托 / 秘境 / 讨伐 / 向导 / 备战」**≥2 个**，单独一个不算
- 找不到「秘境」就返回失败，不加坐标兜底

### ② 原粹 / 浓缩

- 原粹只认 `x/200` 格式。不做名称匹配：界面没有「原粹树脂」这行字，按名称找会命中标签附近最近的纯数字，那个数可能是脆弱树脂的量
- 浓缩只有图标没有文字：模板定位后，数字区取图标右侧紧邻的同尺寸框
- 数字区先用白色数字模板（门槛 0.78，实测真值 0.92、次高 0.62），未命中再 OCR
- OCR 结果按**到数字区中心的距离**排序：数字在框内居中，按「贴左边」算会判成没读到。识别结果不暴露 OCR 置信度，排序只能自己算
- 框内 OCR 的坐标可能以识别区左上角为原点，归一化时对绝对与相对两种基准都做了处理
- 不做字母→数字猜测：`DD` 猜成 `00` 并当有效值返回，比认不出更糟
- 图标坐标超出截图范围时判定坐标系不符，放弃读数

### ③ 「+」

- 轮询匹配加号，命中即点，点后等弹窗出现（超时与间隔见常量表）
- 匹配成功本身即「秘境页已就绪」的判据，不再校验页面

### ④ 须臾 / 脆弱

- 两者共用一条链：模板定位图标，数字区 = 图标正下方、同宽、高 ×0.75
- 数字区先 OCR（两位数照样读得出，实测脆弱 22）；须臾再走数字模板兜底
- 数字模板兜底**只给须臾**：模板只返回单个 0~9，脆弱的两位数会读成其中一位（实测 22 → 2）；须臾上限 9，永远一位数
- 弹窗里只有「须臾树脂」这一行名称，没有「脆弱树脂」字样，所以脆弱只能靠图标定位
- 整屏 OCR 只在「请求了须臾」或「原粹需兜底」时才拍
- 有效期文案由流程层解析（`N天后过期`、`N小时后过期` 记 0 天），弹窗读数不做这件事

### 退出

- ESC 后不截图验证（实测一下就关得掉，省一次全屏 OCR）
- 通知一律在回主界面之后发，避免弹在弹窗上面

## 校验与上限

读数校验最多 3 次、间隔 600ms，每次**重新截图**（错值可能来自瞬时画面，重算同一张图没意义）。

| 情况 | 判定 |
|---|---|
| 非整数 / 负数 | 无效，重试 |
| ≤ 上限 | 有效 |
| 原粹、第 2 次起、`200 < x < 999` | **有效**（原粹可溢出） |
| 其余超上限 | 无效，重试 |

原粹 200、浓缩 5 是真实上限；须臾 9、脆弱 999 只是「合理范围」，用来把明显误读判废。3 次仍无效记 `null`，与真实的 0 区分。

## 输出

日志开框打 UID / 昵称与四项结果；通知四到五行（标题 / 昵称·UID / 原粹·浓缩 / 须臾·脆弱），须臾不足 3 天且持有 >0 时追加一行提醒。样例见 `README.md`。

- 只有原粹、浓缩带上限（200 / 5）；须臾额外带剩余天数
- 失败发「树脂统计失败」+ 原因；四项全 null 时，结果通知之后再补一条错误通知
- 三项设置见 `settings.json`；日志默认只留步骤标题与结果

## 约束

- 配置项与常量改 `src/utils.js`，读数规则改 `src/resin.js`，通知文案改 `main.js`
- 不写死坐标、不给找不到的元素加坐标兜底；要偏移用区域派生
- 不在顶层写执行语句，入口整体包在异步 IIFE 里
- 识别与点击只在流程层，工具层不碰游戏界面
- 不调用 `bettergi.d.ts` 之外的 API，不混用大小写兼容别名
- 不存非 UTF-8 或带 BOM 的文件

改完逐个校验语法（`import/export` 在 `node --check` 的普通 `.js` 上下文会报错，拷成 `.mjs` 再查）：

```bash
for f in main.js src/resin.js src/utils.js; do cp "$f" "/tmp/$(basename ${f%.js}).mjs"; node --check "/tmp/$(basename ${f%.js}).mjs"; done
```

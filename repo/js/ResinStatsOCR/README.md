# 树脂统计（OCR）

> 当前版本 **v6.5**（与 `manifest.json` 的 `version` 一致）

打开冒险手册的「秘境」页，把原粹、浓缩、须臾、脆弱四种树脂一次读全，退出界面后发一条通知。

---

## 输出

日志末尾给出四项结果，同时发一条通知：

```
树脂统计
旅行者 · UID 100000001
原粹 17/200 · 浓缩 1/5
须臾 1（9天） · 脆弱 22
```

须臾剩余不足 3 天时，通知末尾会多一行提醒（读不到有效期文案就不带天数，也不提醒）。

> 通知要送达，得先在**调度器 → 通用设置**里勾上「JS 通知权限」。没勾时日志会出现「JS 通知关闭，消息被拦截」，消息不会进入任何渠道。

---

## 设置

| 项 | 默认 | 说明 |
|---|---|---|
| 完成后发送通知（含失败） | 开 | 成功、失败共用这一个开关 |
| 昵称 | 空 | 通知里显示的名字，留空用「旅行者」 |
| 详细日志 | 关 | 排查问题用，输出识别细节 |

---

## 流程

| 步 | 做什么 |
|---|---|
| ① | 按 F1 开冒险手册，点左侧「秘境」 |
| ② | 秘境页同一屏读原粹 + 浓缩 |
| ③ | 轮询 3 秒匹配「+」并点击 |
| ④ | 弹窗里读须臾 + 脆弱 |
| 退出 | 按 ESC 关弹窗 |
| 收尾 | 回主界面 → 打印结果 → 发通知 |

F1 打不开手册时的备选路径：按 ESC，在 ESC 菜单左上找「冒险之证」点进去（最多 2 次），仍不行再按一次 F1。

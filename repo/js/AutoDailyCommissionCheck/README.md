# 自动每日委托检查

通过 OCR 识别每日委托奖励是否已领取，基于 BetterGI JsAPI 实现。

## ✨ 主要功能

* **自动识别**：通过 OCR 自动识别每日委托奖励状态。
* **智能通知**：支持发送持久化通知，告知委托奖励是否已领取。
* **调试模式**：开启后可输出详细 OCR 原始文本，方便调试坐标和识别问题。

---

## 🚀 使用方法

1. 在调度器中新建一个配置组，将脚本添加进去。
2. **右键点击**脚本，选择 **"修改 JS 脚本自定义配置"**。
3. 根据需求配置各项参数后运行。

### 📌 配置项说明

* **发送通知**

  * 开启后，脚本执行完毕会发送持久化通知（同时输出到日志和通知系统）。
  * 关闭后，仅输出日志，不发送通知。
  * 默认：开启。

<br>

* **调试模式**

  * 开启后，会输出详细的 OCR 原始识别文本和坐标信息。
  * 用于调试识别区域和排查 OCR 问题。
  * 默认：关闭。

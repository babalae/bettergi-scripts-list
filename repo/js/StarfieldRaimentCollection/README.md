# 千星奇域-绮衣珍赏 脚本功能说明

主要功能：全自动完成`千星奇域-绮衣珍赏`并领取奖励，支持自定义额外刷取，脚本结束后自动返回提瓦特

基于 **OCR · 模板匹配** 

## 使用的千星奇域关卡

本JS采用当前绮衣珍赏指定奇域《轰鸣木桩:DPS伤害测试》(GUID: 45694132064) 与 《千星木桩·总伤秒伤dps》(GUID: 24339714898)

也可以使用自定义关卡，在脚本配置内启用 自定义奇域 并在下方guid栏按格式填入两个奇域的guid

## 关于奇域

本JS选用绮衣珍赏指定奇域，若当前奇域已不在名单内，按照以下步骤自行更改

1. 使用默认2分钟等待模板（确保奇域进入后在左上角有退出图标，见下图）

<div align="center">
 <img src="assets/Exit.png"/>
 <p>奇域内左上角退出图标</p>
</div>

   - 在`JS脚本自定义配置`内勾选`自定义奇域-使用2分钟等待模板（自行在下方输入guid）`
   - 在`关卡GUID`内输入奇域的GUID（若有多个则使用`,`隔开）

2. 使用更灵活的自定义动作模板  
   - 在`JS脚本自定义配置`内**取消勾选**`自定义奇域-使用2分钟等待模板（自行在下方输入guid）`
   - 在`关卡GUID`内输入奇域的GUID（若有多个则使用`,`隔开）
   - 打开JS脚本文件夹下`assets/archive.json`，按照已有的格式编写自定义动作
   
   archive.json文件内容示例：
   ```json
   {
     "45694132064": "sleep(41000)|keyDown(D)|sleep(700)|keyUp(D)|keyPress(F)",
     "24339714898": "sleep(61000)|keyPress(Escape)|sleep(1000)|click(978,601)|sleep(1000)"
   }
   ```
   各个指令之间使用`|`分隔，可用的指令如下：  
   `sleep(1000)`:  括号内为ms  
   `keyDown(A)`:  括号内为按键，可用按键参考[虚拟键代码表](https://www.bettergi.com/feats/append/keycodes.html)  
   `keyUp(A)`:  括号内为按键  
   `keyPress(A)`:  括号内为按键  
   `click(x,y)`:  括号内为坐标，x为横轴，y为纵轴，使用部分截屏软件或者PS均可得到此坐标

## 首次使用

第一次运行时，在全局配置中完成以下设置：

1. 填写 你的 **战斗队伍名** 和 **元素采集队伍名**。
2. 为战斗队伍选择对应的 **战斗策略**。
3. 保存配置并运行脚本。

UI中有此处未提到的功能，未经过完整测试，对普通用户来说仅作为尝鲜使用。追求稳定不要尝试。

### 领取历练点并补足每日奖励

开启后，脚本先领取可用的历练点奖励，再读取「每日委托奖励」的 `n/4`：`4/4` 时跳过，未满时只做还缺的委托；无法确认进度时按原流程执行。建议在一条龙中放在消耗树脂的任务之后，后面仍安排「领取每日奖励」完成凯瑟琳领奖和派遣。该选项默认关闭，关闭时照常执行受支持的未完成委托。

## 跳过启动配置面板

首次配置完成后，可以关闭启动时的配置面板：

1. 跳转到 **调度器**。
2. 选择脚本所在的 **配置组**。
3. 右键本脚本，选择 **修改 JS 脚本自定义配置**。
4. 取消勾选 **启动时显示配置面板**。

以后运行脚本时将直接开始执行，不再弹出配置面板。需要修改队伍、战斗策略或其他设置时，可以重新勾选该选项。
## 地区支持情况

- **挪德卡莱**：全部支持，该地区目前均为锄地类委托，流程简单，相比蒙德更稳定。
- **蒙德**：从自动蒙德委托继承，但因为对话委托的存在，稳定性低于挪德卡莱。
- **其他地区**：
  - 目前仅收录尚未充分测试的锄地类委托，没有对话委托，且部分特殊机制的委托未完成。
  - 如果追求每天4个委托全部完成，不建议作为主要接取地区，
  - 但如果你愿意参与测试并反馈，欢迎使用。

建议优先选择 **挪德卡莱** 作为每日委托的主要接取地点，以获得相对稳定的运行体验。

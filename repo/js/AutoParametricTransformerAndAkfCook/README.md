# 自动参量质变仪与爱可菲烹饪

一个 BetterGI 脚本：自动跑图到参量质变仪、按材料计划放入材料、等待质变完成收取，需要时还能切出爱可菲放锅做饭。

## 它能做什么

- 自动执行路径走到参量质变仪前，打开背包把小道具「参量质变仪」部署到地上；
- 按你在设置里写的材料计划，逐项识别、查找、调整数量并放入质变仪，然后开始质变；
- 质变期间可选「角色辅助」：按妮露 > 爱可菲 > 久岐忍 > 芙宁娜 > 芭芭拉的优先级，切出队伍里第一个命中的角色，持续放技能/普攻直到质变完成（专门为了给质变仪回能设计的）；
- 质变完成后自动收取，并记录完成时间；
- 勾选「7天质变冷却」后，距上次质变不足 7 天会自动跳过执行，防止白跑一趟；
- 可选启用「爱可菲锅配置」：跑完质变流程后，自动切出爱可菲长按 E 放锅做饭，做完向后撤退并计时等待。

## 安装与使用

1. 把整个文件夹放进 BetterGI 的脚本目录（通常在 `BetterGI\BetterGI\js` 下，看你的安装位置）；
2. 打开 BetterGI，在「脚本」页找到「自动参量质变仪与爱可菲烹饪」，点设置按钮；
3. 按下面的说明填好配置，勾选需要的功能；
4. 进游戏，站在能正常打开背包/地图的位置，回到 BetterGI 点「执行」。

> 脚本要求队伍满编，路径执行期间不要在后台操作键鼠。

## 配置说明

所有配置都在脚本设置的 settings.json 里，字段含义如下：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `enableCooldown` | 勾选 | 启用 7 天质变冷却。勾选后：距上次质变完成不足 7 天则跳过执行；执行完成后自动记录时间 |
| `lastTransformTime` | 文本 | 上次质变完成时间。仅作展示，手动修改无效，每次运行后自动覆盖 |
| `enableAkfPot` | 勾选 | 启用爱可菲锅配置。勾选后脚本会执行队伍切换、切出爱可菲、跑完质变后长按 E 放锅。队伍必须携带爱可菲 |
| `TEAMname` | 文本 | 队伍名称。启用爱可菲锅配置或角色辅助时必填，用于切换到你保存的队伍 |
| `enableSkillHelper` | 勾选 | 启动角色辅助参量质变仪。勾选后请填写上方队伍名称，队伍需包含辅助角色中的至少一个 |
| `materialPlan` | 文本 | 质变材料计划。格式：`材料名数量@页,材料名数量@页`。例：`白铁块50@三,苹果100@二`。`@页`可写一/二/三（对应养成道具/食物/材料分类页），不写则默认从三到一依次找；数量可填 `max` 选最大；留空则跳过参量质变仪流程 |
| `waitTimeout` | 文本 | 等待参量质变完成超时时间（秒），默认 30 |
| `eWaitSec` | 文本 | 爱可菲长按 E 后等待计时时长（秒），默认 60 |

### 材料计划写法示例

```
白铁块50@三,苹果100@二,慕风蘑菇max
```

表示：在「材料」页找白铁块放 50 个，在「食物」页找苹果放 100 个，再按默认顺序找慕风蘑菇并选最大数量。材料名要和 `Assets/RecognitionObject` 里的图片文件名一致（去掉 .png），不然识别不到。

### 常见组合

- 只想跑质变仪：填好材料计划，勾选「启动角色辅助」，其余不勾；
- 只想用爱可菲锅：只勾「启用爱可菲锅配置」，填队伍名称，材料计划留空；
- 质变 + 放锅全流程：勾选两个功能项，填队伍名称和材料计划。

## 注意事项

- 队伍必须满编，且「启用爱可菲锅配置」时队伍里要有爱可菲；
- 路径终点如果落点有偏差，脚本会自动转动视角重新锁定质变仪，最多尝试 4 个朝向；
- 材料数量调整依赖 OCR 回读数字校准，界面缩放比例请保持 100%；
- 质变确认按钮坐标是按 1920×1080 分辨率验证的，其他分辨率可能需要自行校准；
- 使用「角色辅助」时，辅助角色技能循环里的等待时长是按角色 E 技能 CD 估算的，质变完成后会立即检测并停止；
- 脚本仅供个人学习使用，请遵守游戏用户协议，合理使用自动化功能。

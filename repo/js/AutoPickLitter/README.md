# 提瓦特杂事

## 一、介绍

本脚本适用于原神中一些特殊道具收集、个别成就、特殊操作等。

- 蒙德清泉圣水【收集】
- 璃月铜雀上香【仪式】  
- 稻妻神樱抽签【仪式】【成就】
- 稻妻海螺宝箱【成就】【收集】
- 枫丹监狱领餐【成就】【收集】
- 纳塔领取龙蛋【收集】
- 挪德好运转盘【仪式】
- 挪德今日收获【收集】
- 挪德领取糖雕【仪式】【收集】
- 至冬堡冰淇淋【仪式】【收集】

## 二、环境

在运行本脚本时，需要的游戏环境前提。

- 游戏设置最好为默认。
- 游戏主线最好完成前期任务。
- 游戏中基本的传送点确保开启。
- 游戏分辨率设置为`1920×1080`。
- 游戏中世界权限设置为`不允许加入`。
- 行走位切勿设置为薇斯纳

## 四、食用方法

按照以下顺序进行设置配置
- 运行BGI
- 点击【全自动】
- 点击【调度器】
- 【新增配置器组】
- 自己设置配置组名称并确定
- 点击自己设置的配置组名称
- 【添加】
- 选择【JS脚本】
- 勾选【AutoPickLitter】并确认
- 鼠标右键【提瓦特杂事（收集）】
- 选择【修改JS脚本自定义配置
- 自己看自身情况勾选

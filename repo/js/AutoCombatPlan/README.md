# 自动战斗计划

> 按 UID 读取配置，依当日日型安排体力用途。
>
> **当前处于测试期，尚未稳定。**

## 功能说明

本脚本根据当日活动类型，按用户预先设定的顺序消耗体力。单个账号单次运行仅执行一个目标，结束后发送一条通知。

- 双倍日（地脉 / 盛材 / 祝圣）：按配置次数完成当日双倍（默认 3 次），剩余体力转入日常阶段
- 幽境日：角色养成材料中存在当日可执行条目时，优先执行至树脂耗尽；否则挑战幽境危战，结束后剩余树脂由补刷副本清空
- 普通日：直接执行日常阶段

## 快速开始

首次启动会直接弹出配置面板，无需手动切换运行模式（默认值即为「打开配置面板」）。完成填写并保存后关闭窗口，本次运行即结束，不会进入战斗。日常运行前需将运行模式改为「直接运行」，见下一节。账号按 UID 定位。UID 未填写、或该账号尚无配置时，脚本中止并提示原因。

## 面板配置

面板分三页，下文按使用频率排列：个人、全局、数据库。无 BGI 界面时可改用离线版修改配置，见本节末尾。

### 个人页

| 区块 | 何时使用 | 留空影响 |
|---|---|---|
| 队伍 | 每次战斗 | 战斗队伍必填，保存时校验；场景行留空继承「全局」行 |
| 角色养成材料 | 每日优先从此处挑副本；盛材移涌日、幽境日、普通日（符合日期时）均取首条 | 由「日常体力消耗」承担 |
| 地脉移涌 / 祝圣移涌 | 对应的移涌日 | 放弃当日双倍 |
| 角色养成材料（候补） | 仅盛材移涌日，前列条目均不可执行时启用 | 不参与日常判定 |
| 日常体力消耗 | 前列条目均不可执行时，按序轮换 | 与角色养成材料均未配置时，当日无目标 |

「其他」区：补刷副本——地脉或幽境后剩树脂时清空，留空则保留；幽境 BOSS 序号——幽境日用，留空则当日不挑战；分解开关 + 星级——当日执行过圣遗物或幽境后生效，星级留空则不分解；结束后树脂通知——生成通知时读取终值，留空则不含树脂项，另需在 BGI 设置中开启通知。

注：顺序即优先级——角色养成材料自上而下匹配，执行首个当日产出对应材料的副本（秘境每日开放，变化的是当日材料分组），直至树脂耗尽；日常体力消耗按序轮换，一轮完成后重新开始。除战斗队伍外均可留空保存，不影响保存成功。

### 全局页

1. 建议填写版本起始日期
2. 勾选本版本活动
3. 相关数据留空则按普通日处理，不报错
4. 「禁用日期判定」勾选后不校验日期，视为每日均选中日型；三行移涌与幽境之间只能勾选一项
5. 幽境危战 BOSS 名，仅用于个人配置页提示，无影响
6. 具体活动日程以官方公告为准

### 数据库页

1. 名称按游戏内原文填写，脚本靠它匹配秘境与材料；勾选编辑锁后可修改，表末「＋ 新增」添加行
2. 请随游戏版本更新（新秘境、新国家等）或 BGI 实现新内容后自行添加
3. 脚本更新时将同步更新此处默认数据

### 离线版（无 BGI 的机器）

将 `assets/config.html` 拷贝至目标机器并用浏览器打开 → 导入 → 修改 → 保存后下载 json，手动放回 `config/`（`options.json` 回 `assets/`）。

**仅用于无 BGI 时保存个人配置**，不能运行任务。

## 日常运行

将运行模式改为「直接运行」并加入配置组后，可手动或定时执行。

树脂优先使用浓缩，其次原粹；脆弱与须臾不使用；双倍次数仅消耗原粹。

判定日型  
├ 双倍日 → 双倍阶段 → 读树脂 → 日常  
├ 幽境日 → 养成材料可执行：执行至耗尽（结束）；否则幽境危战 → 剩余树脂由补刷清空  
└ 普通日 → 日常

双倍阶段的目标来源：均在个人页配置，按配置次数执行

| 日型 | 目标 | 未配置时 |
|---|---|---|
| 地脉花型 | 地脉移涌/祝圣移涌 #1：花型 + 国家 | 放弃当日双倍 |
| 盛材日 | 角色养成材料中当日首个可执行条目；均不可执行时转向角色养成材料(候补) | 放弃当日双倍 |
| 祝圣日 | 地脉移涌/祝圣移涌 #2：固定套装本 | 放弃当日双倍 |

日常：养成材料首条可执行 → 打至树脂耗尽，当日结束（不轮换、不补刷）
      否则依轮换取一条 → 取到地脉后有余量则补刷 → 分解 → 通知

日常阶段不按次数停止，由本体执行至树脂不足；轮换为完成模式，一轮内每条各执行一次、全部轮完自动重开，进度存 `config/{uid}.state.json`。

通知格式：

```
自动战斗计划 · 旅行者
盛材日（周四）：双倍 {已完成}/{配置次数} · 树脂 {起始}→{结束}
· 天赋·太山府 ×3（双倍）
· 藏金之花·蒙德（日常）
· 圣遗物·无妄引咎密宫（补刷）
```

## 参考

### 自动补出的日期

填写「版本日期」起始日后自动补出：
| 区块           | 自动补出的日期                     | 依据        |
| ------------ | --------------------------- | --------- |
| 版本结束日        | 起始 +42 天                    | 版本固定 42 天 |
| 幽境危战 #4      | 起始 +7 → +17（第 8 天开、第 18 天关） | 幽境时间窗     |
| 移涌三行 #1–#3   | 起始 +33 → +40（三行同段）          | 移涌排班规律    |
| 限时全开 #6 / #7 | 起始 → +7；起始 +20 → +27        | 一版本两期     |

### 配置文件位置

| 文件                        | 内容                  | 写入方       |
| ------------------------- | ------------------- | --------- |
| `config/_global.json`     | 全局页：版本、移涌、幽境、限时全开   | 面板        |
| `config/_default.json`    | 新建账号照抄的模板（账户层默认值来源） | 面板（开发者选项） |
| `config/{uid}.json`       | 单个账号的全部设置           | 面板        |
| `config/{uid}.state.json` | 轮换已执行进度             | 脚本自身      |
| `assets/options.json`     | 数据库页的清单数据           | 面板        |

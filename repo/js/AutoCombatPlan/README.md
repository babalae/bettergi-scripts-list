# 自动战斗计划

> 按 UID 取配置，自动安排体力去向：地脉双倍 → 幽境危战 → 秘境兜底耗尽。

## 功能说明

本脚本根据当日活动类型，按用户预先设定的顺序消耗体力。单个账号单次运行只推进一个目标。

- 双倍日（地脉 / 盛材 / 祝圣）：优先完成当日 3 次双倍，剩余体力转入日常阶段
- 幽境日：角色养成材料中存在当日可打条目时，优先执行至树脂耗尽；否则挑战幽境危战
- 普通日：直接执行日常阶段
- 运行结束后发送一条通知，说明当日执行内容与树脂变化

以下事项不在本脚本职责范围内：修改游戏内设置、代选圣遗物奖励、判断材料是否已刷够。材料充足后需由用户手动删除列表首行。

## 使用前提

- BetterGI **0.66.0 及以上**。低版本不提供 htmlMask，配置面板无法打开
- 游戏分辨率 16:9，最低 1080P。树脂数据通过截图识别
- 系统需具备 WebView2 运行时（Win10 / 11 通常已预装）
- 请先在 BGI 中配置可用的战斗队伍与战斗策略

## 首次配置

首次启动会直接弹出配置面板，无需手动切换运行模式（默认值即为「打开配置面板」）。完成填写并保存后关闭窗口，本次运行即结束，不会进入战斗。日常运行再把模式改为「直接运行」，见下一节。

账号按 UID 定位。UID 未填写、或该账号尚无配置时，脚本中止并提示原因。

## 面板配置

面板分为三页：全局、个人、数据库。

### 全局页

与账号无关，所有账号共用。此处填写活动时间表，脚本据此判定当日日型。

**只需填「版本日期」的起始日**，其余日期自动补出。之后需要手动做的只有两件事：

1. **勾选**。自动补日期不改动任何开关，勾选当前版本开放的「双倍活动」即可（次数默认 3）。
2. **BOSS 名三格（#5）**。手动补充，选填；名称仅用于个人页显示。

日程以当期官方公告为准：自动补出的日期如有出入，手改对应行即可，不影响其他行。补出的日期明细见文末「附录」。

### 个人页

每个账号一份。自上而下为：队伍 → 角色养成材料 → 地脉 / 祝圣 → 角色养成材料（候补）→ 日常体力消耗 → 其他。

**仅战斗队伍为必填项。** 留空时保存会二次确认，确认后仍可保存，但本体缺少队伍名将无法进入战斗。

**每日可执行目标，以下两项至少配置一项：**

1. **角色养成材料**：天赋 / 武器材料，顺序即优先；仅执行首条当日可打条目，完成后当日结束。
2. **日常体力消耗**：摩拉 / 经验书 / 圣遗物，每日开放，按轮换执行，是普通日最稳定的兜底目标。

其余均为选填，留空仅影响对应日型：

- 地脉花型、祝圣本 → 双倍日执行目标。留空则放弃当日双倍
- 角色养成材料（候补）→ 仅在盛材双倍使用，正选无可打条目时接替
- 兜底副本 → 地脉消耗树脂不稳定，完成后常有余量，剩余部分在此清空；未配置则保留剩余
- 幽境 BOSS 序号 → 留空表示该账号不参与幽境危战
- 圣遗物分解 → 默认关闭，需手动勾选；勾选后按星级上限执行（默认 4 星），星级清空即不执行分解
- 结束后树脂通知 → 决定通知中「树脂 x→y」的终值是否读取

### 数据库页

包含地脉花型、国家、秘境及其产出材料。脚本执行时依据此处数据选择秘境并判定当日是否开放。

默认数据已按游戏现状填写，除新增秘境等情况外无需改动。各表设有编辑锁，勾选后方可修改。

修改后请备份 `assets/options.json`；更新脚本时该文件可能被覆盖。

## 日常运行

配置完成后将运行模式改回「直接运行」，加入配置组，可手动或定时执行。

单次运行的流程：

1. 判定当日日型
2. 双倍日优先执行双倍：3 次，仅使用原粹。原粹不足时提前停止，不以浓缩树脂补充
3. 重新读取树脂，进入日常阶段
4. 日常阶段先检查角色养成材料：存在当日可打条目时执行至树脂耗尽；均不可打时才从轮换列表中取一条
5. 取到地脉条目时：完成后再次读取树脂，仍有剩余则用兜底副本清空
6. 按开关执行圣遗物分解，发送通知

日常阶段不按次数停止，交由本体执行至树脂不足为止，无需自行计算剩余次数。

轮换采用完成模式：不改动列表本身，每完成一条即记入已打列表；一轮内每条各执行一次，全部轮完后自动重新开始。进度保存于 `config/{uid}.state.json`。

跑完收到一条通知，样式如下：

```
自动战斗计划 · 旅行者
盛材日（周四）：双倍 3/3 · 树脂 200→8
· 天赋·太山府 ×3（双倍）
· 藏金之花·蒙德（日常）
· 圣遗物·无妄引咎密宫（补刷）
```

首行是脚本名与账号；第二行是日型、双倍完成度与树脂变化；之后每行一个阶段（双倍 / 日常 / 兜底 / 幽境）。有失败时首行追加「有失败」，失败原因单独成行。

## 附录

### 常见问题

| 现象                 | 原因与处理                         |
| ------------------ | ----------------------------- |
| 启动后直接进入战斗，未弹出面板    | 运行模式为「直接运行」，改为「打开配置面板」        |
| 提示当前版本不支持 htmlMask | BGI 版本低于 0.66.0               |
| 面板白屏或创建失败          | WebView2 运行时缺失                |
| 提示找不到账号            | UID 未填写，或该账号尚无配置。先在配置面板为它建好配置 |
| 双倍未完成即转入日常         | 原粹不足以完成 3 次。双倍仅使用原粹           |
| 地脉完成后仍有一次传送        | 树脂读取失败时无条件执行一次兜底，可能为空跑        |
| 日志提示「轮换列表为空」       | 轮换未配置完整条目，当日日常阶段直接结束          |
| 需重置轮换进度            | 删除 `config/{uid}.state.json`  |

### 自动补出的日期

填「版本日期」起始日后自动补出：

| 区块           | 自动补出的日期                     | 依据        |
| ------------ | --------------------------- | --------- |
| 版本结束日        | 起始 +42 天                    | 版本固定 42 天 |
| 幽境危战 #4      | 起始 +7 → +17（第 8 天开、第 18 天关） | 幽境时间窗     |
| 移涌三行 #1–#3   | 起始 +33 → +40（三行同段）          | 移涌排班规律    |
| 限时全开 #6 / #7 | 起始 → +7；起始 +20 → +27        | 一版本两期     |

### 全局页补充

- 勾选「禁用日期判定，每日执行」后不再校验日期：这一行不看自己填的日期，版本期内天天算这种日型（版本期没填则不限日期）；三行移涌与幽境之间只能勾选一项。
- 全局页留空不会报错，缺少活动数据时一律按普通日处理。

### 配置文件位置

| 文件                        | 内容                | 写入方  |
| ------------------------- | ----------------- | ---- |
| `config/_global.json`     | 全局页：版本、移涌、幽境、限时全开 | 面板   |
| `config/_default.json`    | 新建账号照抄的模板（账户层默认值来源） | 面板（开发者选项） |
| `config/{uid}.json`       | 单个账号的全部设置         | 面板   |
| `config/{uid}.state.json` | 轮换已执行进度           | 脚本自身 |
| `assets/options.json`     | 数据库页的清单数据         | 面板   |

前四份在 `config/` 下，`saved_files` 登的是 `config/*.json` 通配——更新脚本时整目录保留，不只前三份；文件缺了脚本会自己补默认或种子。`assets/options.json` 不在 `saved_files` 里，属于脚本自带的库数据。更换设备时需整体拷贝脚本目录。

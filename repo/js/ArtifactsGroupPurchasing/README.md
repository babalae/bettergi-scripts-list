# AAA 狗粮联机团购
> **注意：此功能需配合莫酱联机工具才能实现联机**
## 一、功能及部分原理说明
1. **联机团购的核心原理**：多人轮流当房主，其余成员进入房主的世界占位加载调查点。因为每个玩家的世界有**各自独立**的调查点（每天各自刷新上限），所以 N 个人轮流当房主、去各自的世界收获这些被队友加载的额外调查点。这是「团购」相对单人狗粮批发的收益来源。
2. **角色分工** ：（通过编号判定，0=单人 / 1=房主 / >1=队员）：
   - **房主（1 号）**：在自己的世界里跑完整路线（前执行 → 后执行），是收益的主要采集者。
   - **队员（2/3/4 号）**：进入房主世界后，仅用「占位」路线占住对应序号的格子（不跑完整路线、避免抢点/卡位），等房主跑完该世界后离开。
3. **两种相互独立的附加路线开关** ：（均默认关闭，互不牵连）：
   - （前执行 / 额外路线）：联机收尾后单人运行时勾选，运行「额外/前执行」分支。
   - （至冬罐罐）：附加独立路线（「额外/至冬」），与前者相互独立，可单独开关。
4. **支持断点续跑与收益上报**：脚本会向 mojang 团购服务端上报每局经验/摩拉，服务端负责排行榜、收益上限与炸车自动冻结（详见 [第四·服务端说明](#四运行原理)）。
5. **支持自动重新**：配合 mojang联机工具，可在联机结束后自动重新上线。

## 二、使用方法及配置

1. 从莫酱联机工具处将脚本更新至 BetterGI 调度器。
2. 右键点击脚本以修改 JS 自定义配置。逐项含义如下：

### 联机运行配置
- **运行模式**：。
  - `使用JSON配置文件`：从 `匹配信息.json` 读取联机信息开始联机。
- **运行时使用队伍（partyName）**：进入联机模式前切换到的队伍名。
- **运行时使用角色的序号**：进入联机前尝试切换到的角色序号。

### 收尾路线配置
- **1p 收尾路线**：1 号（房主）自家世界跑的收尾路线，可选 `枫丹高塔 / 茶叶 / 清籁丸 / 风息花`，默认 `枫丹高塔`。非必要不建议更改。

### 额外路线配置
- **运行额外路线 / 联机收尾**：联机收尾后单人运行勾选；普通模式勾选后运行「额外/前执行」分支；自动进入模式在联机完成后立即执行额外路线。
- **运行至冬罐罐路线**：附加独立路线（「额外/至冬」），勾选后才会执行，与「额外路线」相互独立，请在额外狗粮配置组中勾选。

### 其他配置
- **禁用强迫症模式**：勾选后即使人不齐也执行路线。
- **调试**：勾选后跳过路线执行逻辑，仅供调试。
- **自动重新上线**：联机结束后自动用 `匹配信息.json` 在 mojang 重新上线；填所需最小上线次数，炸车后重新上线不消耗次数，正常当房主跑完一次后自动改为不当房主；填 0 仅运行一次即停，想确保当上房主请填 >0（如 1）。
- **完成 2/3p 路线后提前踢出**：对应占位成员路线跑完即踢出。
- **联机等待一条龙 / 联机后一条龙**：炸车或正常结束后重新上线时 / 正常结束且不再上线时启动的一条龙（需配合 mojang联机工具）。
- **放人模板匹配使用全部图片**：关闭时为每个白名单队员选择文件名最相似的图片。
- **是否通知信息**：打印日志，建议开启。
- **拾取匹配阈值**：误捡调高、漏捡调低，默认 `0.9`。
- **识别间隔毫秒**：两次检测 F 图标之间的等待，默认 `100`。

## 三、快速开始

### 运行前提
- 游戏画面推荐 `1920×1080` 分辨率（识别区域/点击坐标按此配置）。
- 游戏按键保持默认，尤其是调查/拾取 `F` 键。
- 联机工具与BGi都是管理员权限运行

### 联机账号限制
- **账户名称** ：
   - 队伍名不得包含 `\\ / : * ? " < > |`，不能以空格开头或结尾，不能使用 Windows 保留设备名，长度 ≤ 255。
- **联机规则** ：
   - 联机基于公平互利原则
   - 不允许手动中途跳车
   - 其他原因导致的炸车也会对过错方进行惩罚
- **多账号管理** ：
   - 有多个账号参与联机时，每个账号使用独立的 BGI 和莫酱用户端文件夹


## 四、运行原理

### 路线目录结构
脚本路线位于 `assets/ArtifactsPath/`，按「地点」分组，每组含若干阶段子目录：

| 目录 | 含义 | 谁跑 |
|---|---|---|
| `地点/前执行` | 在 2/3/4 号进入**前**，由房主在自家世界执行 | 房主 |
| `地点/后执行` | 踢出 2/3/4 号后，房主补跑的收尾 | 房主 |
| `地点/占位` | 队员进入房主世界后占住对应序号的路线 | 队员（2/3/4 号）|
| `额外/前执行` | 联机收尾后单人附加路线| 房主单人 |
| `额外/至冬` | 至冬罐罐附加独立路线| 房主单人 |

常见地点分组：度假村、智障厅、枫丹高塔、清籁丸、茶叶、踏鞴砂等（依版本更新增减）。

### 运行时间线（手动上线示意）
```text
填写游戏名/UID点击上线进入妙妙屋联机房间（人齐发车）
        │
        ├─ 房主在自家世界：前执行路线，做一些前置准备。
        │
        ├─ 等待队友进入自己世界。
        │
        ├─ 队友执行占位逻辑，各自前往占位点，房主执行占位检查，不通过判定为炸车。
        │
        ├─ 房主开始执行狗粮拾取路线。
        │
        ├─ 房主完成 2/3/4 号路线后提前踢出各路线占位成员。
        │
        ├─ 房主后执行收尾路线。
        │
        └─ 额外配置组：房主单人再跑额外/至冬附加路线。
```

### mojang 团购记录说明
JS 脚本只负责采集与上报；**收益记录、收益上限、炸车冻结、排行榜**由独立的 mojang 服务端处理：
- **收益上限**：单次经验或摩拉 > 15 万会被处理（反作弊），单日经验+摩拉合计 > 26 万在排行榜侧归零。
- **炸车自动冻结**：当天作为过错方参与炸车，普通用户达 2 次、信任用户达 100 次即自动冻结并下线。
- **排行榜**：为收益展示用，不含限制逻辑。
- **积分制度** ：
   - 发车时房主消耗 3 分，队员获得 1 分（每日首次占位额外获得 1 分）
   - 炸车时，过错方扣除 6 分，补偿其余参与者一人 2 分
   - 多次炸车还会触发冻结机制
   - 互相占位时，积分最高的将能够优先成为房主
   - 不排除积分以后还有其他功能
- **联机顺序** ：
   - 积分高者优先当房主
   - 群友联机互惠互利，也有大佬的小号池专用辅助占位。

## 五、队伍配置建议
- **房主（1 号）行走位**：优先迪希雅（耐肘王、提供移速）或万叶（吸狗粮）。
- **移速**：电脑性能一般时降低队伍移速（矮小体型、不用双风等），收益更稳。
- **占位成员**：优先风属性角色。

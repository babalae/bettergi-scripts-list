# 晶蝶诱捕装置

自动放置和收集「晶蝶诱捕装置」，每天运行一次即可。

本脚本基于 ddaodan 的 CrystalflyTrap 2.1 修改，主要适配原神 7.2 的背包/材料界面变化。

## 前置条件

- BetterGI 建议 0.67.0 以上（本版在 0.67.0 测试）。
- 游戏为 16:9，推荐 1920×1080 窗口或同比例分辨率。
- 背包内有「晶蝶诱捕装置」。
- 背包内准备一种数量大于 30 的材料（矿石等，陷阱启动会消耗 30 个）。
- 装置放在**枫丹冒险家协会锚点**附近；脚本会自动传送到该锚点。
- 运行时保持游戏窗口在前台，不要切走或最小化，否则截图/OCR 会失败。

## 运行方式

在 BetterGI 的「全自动 → JavaScript 脚本」中直接运行本脚本，或加入调度器。

本版不需要在脚本设置里勾选“启用”，直接运行即可。

## 状态判断

脚本不再依赖 `status.json` 里的 7 天计时来决定“放置还是收取”，而是打开背包，点击「晶蝶诱捕装置」后识别右下角按钮：

- **「部署」**：装置未部署，进入放置流程。
- **「取消布置」**：装置已经部署，脚本不会点击，直接进入收取流程。

这样即使手动放置过、或者上次运行中断，状态也不会错乱。

## 放置流程

1. 传送到枫丹冒险家协会锚点。
2. 按 `B` 打开背包，按 `E` 循环切页，直到左上角出现「小道具」。
3. 在小道具页找到「晶蝶诱捕装置」并点击。
4. 确认右下角是「部署」后点击放置。
5. 按 `F` 与装置交互，进入材料界面。
6. 先找左下角「最大」：
   - 有「最大」→ 直接点击。
   - 没有「最大」→ OCR 屏幕上方，找到数量最大的材料（数值 >30）并点击，再确认「最大」出现后点击。
7. 点击「启动」，在确认框里再次点击「启动」。

## 收取流程

1. 背包右下角显示「取消布置」时，关闭背包。
2. 按 `F` 收取。
3. OCR 屏幕中央：
   - 出现「晶核」→ 收取成功，点击空白处关闭奖励界面。
   - 出现「诱捕未完成」→ 还没成熟，脚本结束，不修改状态。
   - 都没有 → 记录“状态未知”，不修改状态。

## status.json

脚本会在同目录维护 `status.json`：

```json
{
  "isPlaced": true,
  "collectionTime": 0
}
```

`collectionTime` 只作为记录，不再阻止脚本运行；实际状态以背包里的「部署/取消布置」为准。
`manifest.json` 已把 `status.json` 加入 `saved_files`，脚本更新时不会覆盖它。

## 2.2 更新内容

- 改为按背包「部署/取消布置」判断真实状态，去掉 7 天计时门槛。
- 材料界面支持“先找最大；没有最大则点数量最大的材料（>30）；再确认最大”。
- 收取时识别「晶核」/「诱捕未完成」，成功后点击空白关闭奖励。
- 去掉第二次“启动”后的 `returnMainUi()`，修复窗口失焦时 OpenCV ROI 越界报错。
- 增加「取消布置」保护，避免误点把已部署的装置收回。
- 移除未使用的脚本配置和旧矿石图标依赖。

## 已知限制

- 使用固定 1920×1080 逻辑坐标；非 16:9 或 UI 缩放变化时可能需要调整坐标。
- 材料选择依赖 OCR 对数字的识别；如果界面文字/布局变化，可能需要更新。
- 不保证兼容云原神或其他语言客户端。

# 提瓦特记事本

用于 BetterGI 的原神资源统计脚本。运行一次即可依次统计抽卡资源、摩拉、角色经验书和圣遗物经验，并按账户保存记录。

## 统计内容

- 抽卡资源
  - 原石
  - 纠缠之缘
  - 抽卡资源总价值
  - 可用抽数
- 摩拉
- 角色经验书
  - 流浪者的经验数量
  - 冒险家的经验数量
  - 大英雄的经验数量
  - 经验书总经验
- 圣遗物经验
  - 小经验瓶数量
  - 大经验瓶数量
  - 圣遗物总经验

圣遗物总经验包含可分解的一至四星圣遗物、大小经验瓶和已储存经验。脚本仍会识别这些数据，但记录文件只保留大小经验瓶数量与总经验。


## 设置说明

| 设置 | 说明 |
| --- | --- |
| 抽卡资源 | 多选需要记录的抽卡资源项目 |
| 摩拉 | 勾选后识别并记录摩拉 |
| 角色经验书 | 多选三种经验书数量和总经验 |
| 圣遗物经验 | 多选大小经验瓶数量和圣遗物总经验 |
| 发送统计通知 | 控制是否发送 BetterGI 通知 |
| 账户名称 | 用于区分不同账户的记录文件，仅支持 1～20 位中英文或数字 |

四个资源分类默认均不选择。某个分类至少勾选一项时，脚本才会执行该分类的识别；勾选的具体项目会写入本地记录。

无效或空白的账户名称会自动使用 `默认账户`。

通知还需要在 BetterGI 的调度器通用设置中启用“JS 通知权限”。

## 通知

为避免通知数量过多，全部项目开启时最多发送三条通知：

```text
原石-数量 | 纠缠之缘-数量 | 可用抽数-数量
```

```text
摩拉-数量
```

```text
小经验瓶-数量 | 大经验瓶-数量 | 圣遗物总经验-数量
```

## 记录文件

所有记录保存在 `record` 文件夹中，每个账户使用一个文件：

```text
record/默认账户.txt
record/账户二.txt
```

所有勾选的本地记录项目统一写入当前账户的同一个文件。同一账户再次运行时会追加新记录，不会覆盖旧记录。12 项可自由组合，也可以全部同时记录。摩拉使用原始整数记录。每次运行只在该批记录前写入一次时间：

```text
2026/07/29 15:12:30
提瓦特记事本-可用抽数-16
提瓦特记事本-抽卡资源总价值-2600
提瓦特记事本-摩拉-750767
提瓦特记事本-大英雄的经验-24
提瓦特记事本-冒险家的经验-884
提瓦特记事本-流浪者的经验-1711
提瓦特记事本-经验书总经验-6611000
提瓦特记事本-小经验瓶-20
提瓦特记事本-大经验瓶-5
提瓦特记事本-圣遗物总经验-200000
```

关闭的统计项目不会写入对应记录。

- BetterGI 版本不低于 `0.55`
- 游戏分辨率以 `1920 × 1080` 为识别基准
- 游戏界面语言为简体中文
- 运行前确保角色处于可正常打开菜单的场景

OCR 或图片识别可能受到界面加载速度、分辨率和遮挡影响。如果某项统计失败，可返回主界面后重新运行。

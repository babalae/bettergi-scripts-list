# 砺行修远 · 自动领取奖励

原神「砺行修远」活动的进度奖励自动领取脚本，基于 BetterGI 的 Javascript 脚本能力（BvPage + OCR）。
不扫描整圈，按当前「完成进度 N/8」只点属于这一档的那一个奖励节点。

## 功能

- 按进度自动领奖：读「完成进度 N/8」，只点第 N 档对应节点，1/8 至 7/8 各档各点一次。
- 点完自检：每一档点完读一次弹窗标题，和该档应有的物品名比对，日志里写明命中还是没命中。
- 8/8 收口：点中央宝箱领命座 → 连点右下角 UID 区域关掉详情弹窗 → 点左下「砺行复礼」宝箱。
- 星期闸门：可设置只在指定星期执行，其余日子直接退出，不碰游戏画面。
- 进度可手动：勾选后用手填的 N/8，不勾则走图像识别。

「选择命星」是不可逆的命座兑换，脚本只检测并提示，不会替你点。

## 前置条件

- BetterGI 0.67.0 或更高（manifest.json 中 bgi_version 已按实测版本填写）。
- 游戏分辨率为 16:9 且客户区 1920×1080。脚本内所有坐标按此量取，其他分辨率需自行重算。
- 游戏窗口在前台，BGI 的输入才能生效。

## 安装

1. 把整个 AutoLiXingXiuYuan 文件夹放进 BetterGI\User\JsScript。
2. 重启 BetterGI（脚本目录在启动时扫描，不重启看不到新脚本）。
3. 在调度器里右键该脚本 →「修改JS脚本自定义配置」，按需调整配置项。

从脚本仓库订阅安装则无需手动放文件夹，直接在「脚本仓库 → Javascript脚本」里搜索并订阅。

## 自定义配置

| 配置项 | 类型 | 说明 |
|---|---|---|
| 只在勾选的星期执行 | checkbox | 关闭 = 每天都跑 |
| 允许执行的星期 | multi-checkbox | 周一~周日，可多选 |
| 使用手动指定的进度 | checkbox | 勾上 = 用「手动进度」的值；不勾 = 图像识别 |
| 手动进度 | input-text | 0~8 的数字 |
| 自动打开活动一览 | checkbox | 关闭则需手动停在砺行修远页再运行 |
| 活动一览打开方式 | select | F5快捷键 / ESC菜单 |
| 每次点击后等待(毫秒) | input-text | 默认 900，电脑卡顿时可调大 |
| 每档奖励名 | input-text | 8 项，分号分隔，用于点完自检 |
| 7 个节点坐标 1/8→7/8 | input-text | x,y 分号分隔，从外到内 |
| 8/8 中央宝箱 X/Y | input-text | 第 1 次点击 |
| 砺行复礼宝箱 X/Y | input-text | 关弹窗后第 2 次点击 |
| UID 区域 X/Y、最多连点次数 | input-text | 关详情弹窗用 |
| 点空白关闭弹窗 X/Y | input-text | 1~7 档弹物品详情时用 |
| 调试模式 | checkbox | 打印 OCR 识别结果，排错用 |

## 运行机制

- 星期闸门最先执行：不在勾选列表就直接 return，不碰游戏画面。
- 领取成功判定为 OCR 读到「领取成功」；读到「当前拥有」「限时活动奖励」「角色天赋素材」「命之座」则视为物品/命座详情弹窗，用空白点关闭后继续。
- 判定弹窗时故意不使用「命星」关键词：活动页本身就有「选择命星」按钮和「兑换命星奖励」文案，用它判弹窗会永不满足、连点不止。
- 8/8 关弹窗要求连续两次确认「弹窗消失 + 活动页可见」才停，OCR 读到空结果会延迟重读一次，用来抗日偶发卡顿。

## 已知限制

- 8/8 的砺行复礼宝箱依赖「次周解锁」的账号状态，脚本按实际界面截图与手动操作顺序实现；账上没有解锁时会在日志里提示。
- UID 连点关弹窗依赖游戏当前版本的行为；如果某版本关不掉，脚本会 warn 并跳过第二次点击，不会盲点。
- 进度识别失败时脚本直接中止并打印错误，不会乱点。识别不稳定可勾「使用手动指定的进度」临时绕开。

## 反馈

提 issue 时请附日志（勾选调试模式跑一次），注明：当前进度值、卡在哪一步、以及「奖励校验」和「UID 点击第 N 次」相关的几行输出。

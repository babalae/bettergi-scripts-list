# 只要大瓶极速版

基于原作者 **mno** 的 BetterGI 脚本《只要大瓶》制作的高速版本，用于自动选择并分解圣遗物狗粮，尽量将储存经验转换为大瓶。

- 作者：**Purfeather**
- 版本：`1.0.1`
- 适配：原神 `7.0`、BetterGI `0.64`
- 原脚本：[bettergi-scripts-list / 只要大瓶](https://github.com/babalae/bettergi-scripts-list/tree/main/repo/js/%E5%8F%AA%E8%A6%81%E5%A4%A7%E7%93%B6)

## 更新记录

- `1.0.1`：采用更紧凑的默认点击延迟，少量提升点击速度。

## 脚本特点

- 按界面顺序快速选择圣遗物，达到目标经验瓶后自动分解。
- 支持设置允许分解的最高星级。
- 五星圣遗物始终受到保护，不会进入选择队列。
- 支持“只要大瓶”和“只要小瓶”两种模式。
- 可识别背包中的大小瓶数量，并按设定的临界值自动切换模式。
- 支持调整识别阈值和点击延迟，兼顾速度与稳定性。
- 识别结果存在冲突时会跳过对应圣遗物，避免误选。

## 使用方法

1. 在 BetterGI 中添加并运行“只要大瓶极速版”。
2. 打开自定义配置，设置允许分解的最高星级。
3. 选择目标经验瓶类型：
   - **只要大瓶**：尽量以大瓶为目标进行分解。
   - **只要小瓶**：以小瓶为目标进行分解。
4. 如需自动切换模式，填写“自动切换临界小瓶数量”：
   - 小瓶数量达到或超过设定值时，使用“只要大瓶”。
   - 小瓶数量低于设定值时，使用“只要小瓶”。
   - 留空则使用手动选择的目标经验瓶类型。
5. 首次运行时请观察至少一轮完整过程，确认识图和点击均正常。

## 参数调整

默认识别阈值和点击延迟已经过实际测试，一般无需修改。

如果出现漏选，可适当降低圣遗物星级识别阈值；如果出现误识别，可适当调高。若点击偶尔未生效，优先增加“点击后稳定等待”时间。

调整参数后，建议先使用少量材料进行测试。

## 资源说明

`Assets/RecognitionObject` 保存脚本使用的界面按钮、圣遗物星级、经验瓶产物及背包数量识别图片；其中 `背包物品数字` 子目录保存数字 `0`～`9` 的数量识别模板。

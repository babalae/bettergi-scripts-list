# 全自动周一（AutoMonday）

一站式执行《原神》中的多项每周、每月任务，包括参量质变仪、爱可菲料理、纪行周常、四方八方之网、投资券和星尘兑换。

## 功能

- 参量质变仪：选择投入材料，并使用电气水晶或法器角色充能
- 爱可菲料理机关：独立启用、独立选择充能方式
- 纪行周常：烹饪、锻造、首领击败和秘境挑战
- 纪行满级检测：达到 50 级后，可按任务分别跳过纪行周常
- 每周购买四方八方之网
- 每周提交投资券
- 每月使用星尘兑换粉球、蓝球
- 多账户冷却记录；任务失败后继续执行后续任务

## 使用方法

1. 将本脚本添加到调度器。
2. 右键脚本，打开 JS 自定义配置。
3. 按需启用任务并填写相关配置。
4. 阅读本说明及注意事项后，勾选“我已认真阅读 README”。
5. 从游戏主界面启动脚本。

建议首次运行时只启用一个任务，确认路径、队伍和战斗策略均可正常使用后，再逐步启用其他任务。

## 配置说明

| 配置 | 何时需要 | 说明 |
| --- | --- | --- |
| 账户名称 | 多账户使用时 | 用于区分各账户的冷却记录；单账户可留空 |
| 质变仪任务 | 按需 | 可选择材料与充能方式 |
| 质变仪队伍 | 选择“法器角色充能”时 | 填写包含充能角色的队伍名称 |
| 爱可菲任务 | 按需 | 与质变仪任务互相独立，分别记录冷却时间 |
| 爱可菲队伍 | 启用爱可菲任务时 | 必须是包含爱可菲的队伍 |
| 纪行满级跳过项 | 按需 | 可分别跳过烹饪、锻造、首领和秘境任务 |
| 烹饪任务 | 按需 | 填写菜品名称和制作数量 |
| 锻造任务 | 按需 | 可选择水晶块、紫晶块或萃凝晶 |
| 战斗队伍 | 启用首领或秘境任务时 | 需同时配置对应的自动战斗策略 |
| 四方八方之网、投资券 | 按需 | 首次使用前请确保对应区域已解锁 |
| 粉球、蓝球兑换 | 按需 | 每月各自独立执行 |

## 重要注意事项

1. 烹饪任务所选菜品必须已解锁“自动烹饪”，并准备足够材料。
2. 锻造任务固定执行 20 次，请提前准备足够矿石。
3. 电气水晶充能速度较快，但可能受附近怪物或水晶采集状态影响；法器角色充能较稳定但速度较慢，目前仅支持芭芭拉。
4. 爱可菲和参量质变仪是两个独立任务，队伍、充能方式与冷却记录互不影响。参量质变仪完成后按 **6 天 22 小时**记录下次执行时间。
5. 质变材料默认使用薄荷。若需使用配置列表之外的材料，可替换 `assets` 中对应的识别图片；替换前后材料须位于背包同一分类，文件名保持不变。
6. 只要启用任一“纪行满级时跳过”选项，脚本就会在任务开始前检查一次纪行等级。检测失败时会继续执行任务，避免误跳过。
7. 首领任务使用爆炎树、急冻树场景；秘境任务使用太山府中的牛头人与讨债人场景。请提前配置可用的战斗策略。
8. 四方八方之网和投资券任务需要提前解锁相关地图或任务。投资券相关成就完成后，请关闭对应选项。
9. 脚本会将任务冷却记录保存在本地 `record` 目录中。更新脚本时请保留该目录。
10. 部分周常一周只能实际测试一次，若遇到问题，请附上日志和复现步骤反馈。

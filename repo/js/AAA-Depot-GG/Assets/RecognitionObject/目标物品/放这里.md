# 目标物品截图放这里

```
目标物品/
├── 料理/    <- 料理类物品的截图放这里
├── 材料/    <- 材料类物品的截图放这里
└── 不执行/  <- 暂时不想用的图丢这里（脚本只扫 料理 / 材料，其它子目录一律不扫）
```

## 怎么用

1. 把截图 PNG 放进对应分类的文件夹（比如 `料理/美味的提瓦特煎蛋.png`），**文件名随意**。
2. 右键脚本 → 修改 JS 自定义配置，选两项：
   （分类不用选：图放在哪个子目录，脚本就从那里反推分类、自动点对应的装置页签）
   - **目标物品**：**下拉选择**要存入的那个（**别选第一项「刷新当前图库」**——那表示还没选，
     不是按钮；真要刷新图库是把截图丢进目录后**再启动一次本脚本**）
3. 运行即可。第一次跑（或刚加/删过图）时脚本会自己重写下拉选项并停下，
   **再启动一次**就能在下拉里看到新名字。

## 下拉是自动刷新的（BGI 里没有手动刷新按钮）

脚本每次启动都会扫这个目录，把里面的 PNG 名字（去掉 `.png`、排除占位图 `截图方法模板.png`）和下拉选项比对：

- **有增减** → 直接改写 `settings.json` 重建下拉，默认项重置为「刷新当前图库」（下拉里的显示文案），
  日志打「已完成刷新」→ **本次停止**。
  **再启动一次本脚本**，下拉里就是新名单，选好后再启动即可正式运行。
  （BGI 自定义设置里没有「刷新自定义配置」这种入口，重启脚本就是刷新。）
- **没增减** → 正常往下跑，且**只认你选中的那一张**，目录里其他图不会被当候选。

所以：加图 / 删图 / 改名都不用动代码，也不用手动改设置项内容。

## 更新脚本不会删掉你的图

BGI 更新脚本时会把这个脚本目录整个删掉再重拷。本目录已在 `manifest.json` 的 `saved_files` 里，
**更新前会先备份、更新完再还原** —— 你自己丢进来的截图不会丢。

（同一份名单里还有 `debug/`，所以历史排障日志也保得住。）

## 截图注意

- 分辨率必须和运行时一致（16:9，建议 1920×1080 窗口化）；
- 关掉 HDR、显卡滤镜，游戏亮度保持默认；
- 存 PNG，不要缩放、不要 JPEG；
- 尽量只截目标本体，别把数量角标、选中高亮、相邻条目截进去——那些会变，一变模板就失效；
- 「截图方法模板.png」是占位图（**磁盘文件名保持不变**），它在下拉里显示为「刷新当前图库」；
  分类目录里缺了脚本会自动从 `Assets/RecognitionObject/截图方法模板.png` 拷一份。

**运行记录与多账户**

- 运行记录保存在 `record/账户名/records.json`，每个商人点位独立记录
- 买满5个或商品售罄后，该点位记为本周完成，周四凌晨4点刷新前再次运行会自动跳过；若运行途中中断，再次运行会从断点继续（已完成的点位跳过，没买完/失败的点位自动重试补买）
- 本周勾选的商人全部完成时，脚本会直接跳过运行

**账户名称设置**

- 账户名用于区分多账户的运行记录，默认为"默认账户"，记录保存在 `record/你填的名称/records.json`
- 名称中的路径非法字符（\ / : * ? " < > |）会自动替换为下划线
- 留空则通过OCR自动识别当前游戏 UID 作为账户名，识别失败时使用"默认账户"文件夹

**取消运行限制**

勾选后无视记录强制重跑所有勾选商人，仅本次生效，运行后会自动取消勾选，下次如使用此功能需要再次勾选。

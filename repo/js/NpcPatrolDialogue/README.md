# NPC巡逻对话

按录制好的路线走到目标 NPC 附近，在 F 交互列表里确认选中了目标后再按 F 对话，对话结束后停止。想在某个 NPC 身边循环寻找时可以用它，比如每日委托里需要在人群里找人的任务。

## 用法

1. 在 JS 脚本列表里启用「NPC巡逻对话」。
2. 在设置里填 NPC 名称、路线文件名和巡逻环起点编号；路线文件放在 `assets/Pathing/` 下。
3. 站在路线起点附近运行。脚本先用 BGI 原生回放入口路线（保留飞行和收翼动作），到达后再进入大厅巡逻，每一圈交替正序和倒序。

## 参数

| 设置 | 含义 |
| --- | --- |
| 要寻找的 NPC 名称 | 交互列表里显示的名字，会忽略空格和常见标点 |
| 巡逻路线文件 | `assets/Pathing/` 下的 JSON，需包含传送起点 |
| 巡逻环起点编号 | 巡逻环第一个点在原路线里的编号，从 1 开始 |
| 安全下楼回放点位数量 | 路线开头有多少个点用于入口回放 |
| 最多巡逻圈数 | 走完仍没找到就停止 |
| 巡逻总超时（秒） | 从入口回放结束后开始计 |
| 到达点位的判定距离 | 小地图坐标单位 |
| 不启用自动剧情 / 自动吃药 | 默认关闭这两个触发器，按需改回 |

## 识别内容

`assets/RecognitionObject/` 里的 F 提示、聊天气泡、派蒙菜单和对话图标模板来自 BGI 自带资源。脚本按 1920×1080 参考分辨率等比缩放坐标，非该分辨率下需要先确认模板能识别到。

## 与原加载器补丁的区别

原先的做法是给「自动剧情加载器」加一条 `巡逻对话` 指令，再由加载器从任务目录读取并执行 `巡逻对话.js`。本脚本把这段逻辑收进自己的 `src/patrol.js`，作为独立 JS 脚本运行，不需要修改加载器，也不从任务目录动态执行代码。任务数据只需保留路线 JSON。

## 当前验证情况

已做 JavaScript 语法检查和模拟测试，覆盖：从多个交互行中选对 NPC、同时出现两个 NPC 时滚轮切换、交互重试、没有 F 提示时不交互、卡住后后退重试、入口失败即停。

**尚未完成真实游戏环境的完整实测**：界面模板匹配和滚轮方向需要在实际游戏里再跑一遍确认。没有确认前请不要把它当成稳定可用的版本。

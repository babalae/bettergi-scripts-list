简单介绍：
脚本支持选择普通便携锚点或兹白的好感物品「青玄乘阳华盖」。
脚本每六天会重置一次便携锚点的 CD，之后一直连续包月。
首次运行会自动续费一次, 另外补充一个小知识，两种锚点只能存其一。

具体使用方法：
首先你需要学会录制地图追踪，不会的自己去官网学。
地图追踪文件的第一个点位，是你需要放置锚点的点位，类型选择传送，动作选择其他里面的强制传送。制作好的地图追踪文件，命名为"续费"放入脚本的assets文件夹中。
此外，强烈建议额外录制一个完整前往便携锚点的地图追踪文件，当你长期不登录, 或者你临时又放置了一个锚点, 会导致你之前的锚点无法正常续费，录制了这个文件可以用于恢复锚点。文件需要命名为"恢复"，放入脚本的assets文件夹中。
最后制作好的地图追踪文件，录制完成后，一定要测试一下。看恢复文件能否正常前往指定地方，看续费文件能否正常传送到指定位置。

使用细节：
详细讲一下恢复流程，当需要续费的锚点不存在的时候，首先会经历传送失败的情况，这个过程等待的时间会比较长，大约30s，这是BGI本体的原因，之后如果有用于恢复的地图追踪文件，就会开始正常恢复了。

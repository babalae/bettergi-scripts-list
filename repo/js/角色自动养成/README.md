# 角色自动养成 · BetterGI JS 脚本

> **作者**：[aipaixiatian](https://github.com/aipaixiatian) ｜ **仓库**：[Automatic-Character-Growth](https://github.com/aipaixiatian/Automatic-Character-Growth) ｜ **反馈**：[提 Issue](https://github.com/aipaixiatian/Automatic-Character-Growth/issues)
> **版本**：v1.0.0 ｜ **要求**：BetterGI ≥ 0.66.0 ｜ **数据**：游戏 7.2

**告诉它「谁练到多少级、天赋几级」，它自己算材料缺口、读背包、排体力，该刷的刷完就停。**

## 核心特点

1. **只补差额**：背包数量用 BGI 内置能力一次读完，`目标 − 现有 = 缺口`，够了一点不刷
2. **支持「当前 → 目标」**：`胡桃 22>90 6/6/6>9/9/9`，已吃掉的突破、已升完的天赋不重复刷
3. **体力优先排序**：秘境（自动判断今天开不开）→ 世界首领 → 采集特产 → 打怪
4. **地脉花补尾**：经验书按背包缺口自动算次数；摩拉只能预估（不是背包物品，读不到存量）
5. **不白烧体力**：今天不开的本直接跳过并写明可刷日期；体力预算用完的任务留到下次
6. **防坑设计**：识别失败绝不当 0（不会无限刷）、路线卡过拉黑 3 天、连续失败熔断、进程被杀 CD 也不丢

## 用前须知（踩过的坑）

- **自动拾取模式建议改「黑名单」**：BGI 若为「白名单」模式，不在清单里的材料一律不捡（白名单是英文名清单，常常漏）
- **采集路线分「有草神 / 无草神」**：有纳西妲就用有草神路线（脚本里可选），否则会自动退回按键拾取（屏幕上真出现 F 提示才按，不会乱按触发 NPC 对话）
- **别最小化游戏窗口 / 别切走焦点**：BGI 会取消任务，脚本会当作中断退出
- **秘境材料有开放日**：天赋书/武器材料每周只开 3 天，脚本会跳过并提示，这是正常行为
| --- | --- |
| 材料总账 | 内置游戏 7.2 数据（126 角色 / 254 武器）：突破、天赋、武器突破全部折算 |
| 只补差的 | 背包数量用 BGI 内置 `CountInventoryItem` 一次读完，**目标 − 现有 = 缺口** |
| 刷体力 | 秘境（天赋书/武器材料）→ 世界首领（突破素材），都走 BGI 内置自动秘境 / 自动首领 |
| 世界采集 | 跑你**已订阅**的地图追踪路线，按产量优先选路线，记 CD 防重复跑 |
| 打怪 | 同上，战斗完全由 BGI 地图追踪 + 自动战斗执行 |
| 地脉花 | 经验书按缺口自动算次数；摩拉给预估（摩拉不是背包物品，读不到存量） |
| 不做的事 | 周本（限次）、元素晶体（无专属秘境）、皇冠 —— 只报告不刷 |

## 前提条件

1. **BetterGI ≥ 0.66.0**（用到 `CountInventoryItem` / `AutoDomainParam` / `AutoBossParam` / `AutoLeyLineOutcropParam`）
2. 想采集 / 打怪，必须先订阅**地图追踪**（地方特产 / 敌人与魔物）
3. 建议在 BGI「自动战斗」里选好策略（如「根据队伍自动选择」），秘境 / 首领会跟随你的配置

## 三步上手

1. 把本目录整个放到 `BetterGI\User\JsScript\角色自动养成\`
2. 刷新 BGI 脚本列表 → 右键「修改JS脚本自定义配置」→ 填 **养成计划**：

   ```
   胡桃 22>90 6/6/6>9/9/9 护摩之杖 1>90
   ```

   - `22>90` ＝ 当前 22 级升到 90 级（会跳过已经吃掉的突破材料）
   - `6/6/6>9/9/9` ＝ 天赋从 6/6/6 升到 9/9/9
   - 武器可省略；只写角色名 ＝ 90 级、天赋 1/1/1
   - 多个角色用 `|` 分隔，或写进 `record/plan.txt`

3. **运行模式先选「演练（不执行）」**，看日志里的计划表；没问题再改「执行」

## 配置项（分组显示）

| 组 | 关键项 |
| --- | --- |
| ① 养成计划 | `planText`：角色名 + 等级 + 天赋（+ 武器） |
| ② 体力与范围 | 原粹树脂预算、脆弱树脂、采集 / 打怪开关、地脉花次数、经验书目标本数 |
| ③ 队伍 | 秘境 / 首领 / 采集 / 打怪 四套队伍名（留空 = 沿用 BGI 或保持当前队伍） |
| ④ 补映射 / 自学习 | 怪物掉落→敌人 的补充映射；打怪映射自学习（跑前后对比背包自动学） |
| ⑤ 高级 | 战斗策略名、路线数、轮数、CD、卡死拉黑、超时与熔断 |

## 防坑设计

- **秘境开放日**：天赋书 / 武器材料每周只开 3 天，今天不开就跳过并提示可刷日期
- **识别失败不当 0**：`-2` 会重试，仍失败记「未知」并**不参与刷取**
- **防卡死**：停止按钮立刻收手；路线报错 / 超时 / 被按停止 → 拉黑若干天；连续失败熔断；总时长上限
- **崩溃安全**：每跑完一条路线立刻把 CD 写进 `record/cd/<材料>.json` 分片，BGI 被强关最多丢一条
- **演练模式**：不点、不跑、不切队伍，只打印计划

## 数据来源

`data/` 由 [genshin-db](https://www.npmjs.com/package/genshin-db)（游戏数据 7.2）生成；
秘境入口名用 BGI 自带 `tp.json` 校验；首领名取自 BGI `AutoBoss` 资源；
怪物掉落来自 bwiki 敌人页 + 人工确认 + 运行时自学习。

游戏更新后新角色会提示「数据里没有这个角色」，需等数据更新。

## 常见问题

- **全部跳过、什么都没跑**：多半是地图追踪没订阅，或今天对应秘境不开（日志会写原因）
- **背包统计很久 / 有未识别**：翻页识别偶尔失败，脚本会重试并跳过未知项，不会乱刷
- **首领被跳过**：该素材还没建立「素材→首领」映射，可在设置里补一行 `素材名=首领名`
- **名字写错**：会给出候选（`胡陶 → 胡桃`）并退出，不会跑错人

## 目录结构

```
角色自动养成/
  manifest.json      脚本声明（BGI 读这个）
  settings.json      37 项配置（分组显示）
  main.js            主流程
  lib/planner.js     需求→目标→缺口→任务队列（纯逻辑，可单测）
  lib/routes.js      地图追踪路线索引 / 材料匹配 / CD / 卡死黑名单
  lib/executor.js    秘境 / 首领 / 采集 / 打怪 / 地脉花 / 自学习
  lib/inventory.js   背包数量读取（CountInventoryItem 封装）
  lib/store.js       数据加载 / 分片 CD 持久化
  lib/env.js         日志 / 通知 / 停止检测 / AutoSkip 开关
  data/*.json        游戏数据（角色/武器/材料/秘境/首领/怪物映射）
  record/            运行记录（计划、CD 分片、状态、日志）
  test/core.test.mjs 36 项单测（可用 Node 跑，无需游戏）
```

# 地图圆盘 MapDisc

在小地图上盖一层透明圆盘，圆环套住小地图，永远指向「下一个要去的任务点」：

- 任务点在小地图范围内 → 盘内一个红点，位置就是真实相对位置
- 任务点超出范围 → 圆环外沿一个箭头指方向，附带距离
- 走到任务点附近自动划掉、指向下一个，适合按顺序跑任务 / 采集

鼠标完全穿透，不影响游戏操作。脚本不联网，所有数据都在本地。

## 安装

把整个 `MapDisc` 文件夹放进 `BetterGI\User\JsScript\` 下，重启 BetterGI，
在「全自动 → JS 脚本」里就能看到「地图圆盘」。

## 使用

1. 编辑 `tasks.txt`，一行写一个任务点：`X, Y, 名字`（存盘 2 秒生效，不用重启脚本）
2. 进游戏大世界，圆盘出现并指向第一个任务
3. 走到任务点 8 米内待一小会儿，脚本自动把这一行注释掉、指向下一个

tasks.txt 本身就是进度记录：做完的任务被注释掉、盖着完成时间，重启不会从头再来。

### 坐标哪里抄

游戏内不显示坐标。两个来源：

- BGI 自带传送点表 `GameTask\AutoTrackPath\Assets\tp.json`，每个传送点的
  `position` 是 `[X, 高度, Y]`，抄第 1 个和第 3 个数
- 直接走到目标位置按 F9，把当前位置记成一个任务

## 热键

| 键 | 作用 |
|---|---|
| F9 | 把当前位置追加为一个任务 |
| F8 | 手动完成当前任务，指向下一个 |
| Insert | 圆盘位置标定（方向键挪、`+`/`-` 改半径、Home 复位，退出自动保存） |
| `\` | 截一张小地图存到 `assets/shot_minimap.png`（做图标识别模板用） |

## 常见调整（都在设置里）

- 红点总是偏内 / 偏外：改「小地图半径 = 多少米」（默认 60）
- 红点方向整体镜像或偏 90°：改「北的角度」（默认 -90）
- 圆环没套准小地图：按 Insert 标定，退出自动保存
- 朝向箭头和游戏自带箭头对不上：改「朝向偏移」（默认 90）
- 到达判定太灵敏 / 太迟钝：改「到达半径」（默认 8 米）和「停留时间」（默认 1.2 秒）

## 自动识别任务图标（可选）

设置里勾上「自动识别」后，脚本会用模板匹配在小地图上找任务图标，找到就画成黄色标记。

需要先准备一张图标模板：游戏里按 `\` 截一张小地图（脚本会自动隐藏圆盘再截），
从截图里裁出任务图标存成 `assets/task_icon.png`。识别分阈值 `autoScore` 默认 0.75，
命中率高就不用动；乱指就调高，找不到就调低。

# 自动每日委托

## 重要

> [!WARNING]
> AutoCommission 1.0 当前处于测试阶段，运行结果仍存在不确定性。更新到 1.0 即代表你已了解并接受这些风险；求稳用户请暂时保留 0.98.x。

挪德卡莱地区基础委托功能目前已稳定。

## 从 AutoCommission 0.98.x 升级

1.0 版本继续发布到原来的 `AutoCommission` 脚本目录，已有订阅和调度器任务无需重新添加。

首次正常运行时会在打开配置面板前自动迁移旧版设置：

- `team` → 全局战斗队伍
- `elementTeam` → 全局元素采集队伍
- `prepare = true` → 跳过七天神像及完成后的安全地点传送

已有 Nova 配置优先，迁移只补充尚未配置的项目。旧版开发者选项 `skipRecognition` 不迁移。

## 首次使用

### 第一步：添加脚本到调度器
1. 订阅本脚本
2. 在将脚本添加至调度器**不要直接运行**

### 第二步：配置脚本设置
右键点击脚本，选择「修改 JS 自定义配置」：

1. Nova 新用户勾选 **启动时显示配置面板**；从 0.98.x 自动迁移的用户无需勾选。
2. 运行脚本，在配置面板填写 **战斗队伍名**、**元素采集队伍名**并选择战斗策略。
3. 保存配置并关闭面板，之后可取消勾选 **启动时显示配置面板**。

### 第三步：配置调度器设置
- 战斗超时设为40-60秒
- 最好关闭自动战斗-战斗后自动拾取掉落物，避免浪费大量时间

## 跳过启动配置面板

配置面板默认不显示。需要再次修改配置时：

1. 跳转到 **调度器**。
2. 选择脚本所在的 **配置组**。
3. 右键本脚本，选择 **修改 JS 脚本自定义配置**。
4. 勾选 **启动时显示配置面板**，运行一次脚本并完成修改后再取消勾选。

以后运行脚本时将直接开始执行，不再弹出配置面板。需要修改队伍、战斗策略或其他设置时，可以重新勾选该选项。

## 地区支持情况

- **挪德卡莱**：全部支持，该地区目前均为锄地类委托，流程简单，相比蒙德更稳定。
- **蒙德**：从自动蒙德委托继承，但因为对话委托的存在，稳定性低于挪德卡莱。
- **其他地区**：
  - 目前仅收录尚未充分测试的锄地类委托，没有对话委托，且部分特殊机制的委托未完成。
  - 如果追求每天4个委托全部完成，不建议作为主要接取地区，
  - 但如果你愿意参与测试并反馈，欢迎使用。

建议优先选择 **挪德卡莱** 作为每日委托的主要接取地点，以获得相对稳定的运行体验。

## UID 说明

UID选填，仅用于区分不同账号下的委托，但要注意：
- UID要么不填写，自动识别
- 要么所有账号的UID都要填写，否则可能不执行未填写UID的账号

## 常见问题解答

### Q1: 为什么打开冒险之证脚本就出错？
请检查BGI快捷键-停止当前脚本/其他工具快捷键是否绑到F1，如果是请换一个按键，F1是打开冒险之证的快捷键。

### Q2: 为什么不打怪？
- 确保已正确配置战斗策略[战斗策略编写文档](https://bettergi.com/feats/task/domain.html)

### Q3: 为什么打不到塔上的怪？
- **你带芙芙了吗，没有快去带呀**
- 还有一些真打不到，请将战斗超时设为40-60秒（看个人练度）

### Q4: 为什么有的委托无法完成？
- 先看BGI文档能不能解决[BGI文档](https://bettergi.com/doc.html)
- 战斗委托无法完成99%都是配队问题**你带AOE了吗**
- 反馈问题请将 BetterGI/log/ 目录下当天的日志和委托任务截图反馈给作者，以便排查问题。

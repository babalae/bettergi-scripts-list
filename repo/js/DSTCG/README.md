# 「牌圣」(Duel Saint of TCG)

基于 BetterGI 的七圣召唤自动对战脚本。对局中任意阶段（初始手牌、重投骰子、我方/敌方回合）都可以启动，脚本会自动接管出牌、切换角色、释放技能、元素调和、重投骰子与结束回合，并把每一步决策记录到 `logs/` 目录，可用于训练本地模型。

## 功能一览

- **任意阶段启动**：自动识别当前界面（初始手牌、重投骰子、行动阶段、结束阶段）并接管对局，不需要从开局运行；结束阶段只等待自动结算，不会做无效点击。结束回合前会先关闭左侧的角色/技能/手牌详情面板（它会盖住左下角的结束回合按钮），点完按钮后校验行动权，没结束会重点一次；连续约三分钟（20 次决策）牌局毫无变化会自动退出并保存现场截图，避免整局卡死。
- **自动对战**：识别双方角色、血量、出战位、充能、元素附着、骰子与手牌，自动选择并执行动作。
- **行动牌**：自动打出事件牌、支援牌、场地牌与装备牌；装备/圣遗物牌会自动选中角色并点击确认。同一角色同槽位只装一件，已装备时改给其他角色，所有角色都占用就跳过，避免顶替掉原来的牌。支援区满 4 张后，只有明显更好的支援牌才会顶替场上最差的一张，否则跳过；需要手动选召唤物目标的牌（如「送你一程」）脚本还不会点目标，会直接跳过而不是白交一次行动。
- **结束阶段结算**：召唤物与我方/敌方支援牌、场地牌的“结束阶段”效果都会解析成伤害与治疗，计入阵亡风险评估、结束回合的打分和对局轨迹，避免把最后一颗骰子用在即将被召唤物打死的角色身上。已打出的牌会额外读取卡面徽标：右上角的剩余次数/持续回合/倒计时，左下角的元素图标与当前数值（伤害或治疗），徽标数值优先于卡面文本，像黑色幻影这类按攻击力动态结算的伤害也能读到实际值；徽标数字读空时会分区域重试，元素颜色只作未知牌的兜底判断。卡牌库里没有的牌会点开左侧详情面板读描述，同样能取到结束阶段伤害/治疗/元素。结算伤害还会按元素计入元素反应加成，让模型区分“1 点物理”与“2 点蒸发”。
- **异常状态感知**：冻结等会让角色无法行动的异常状态会被识别（`DISABLING_STATES`），出战角色被冻结时不放技能、优先换人；状态词表按卡牌库预留了眩晕/石化/束缚，补上模板即可生效。
- **元素反应与主攻手**：读取敌方出战角色的附着元素，技能按元素反应收益加权，蒸发/融化/超载等 +2 反应额外优先，冻结、感电/超导/扩散的溅射价值也计入打分；同时评估后排角色的技能与元素爆发潜力，值得时先切换主攻角色再输出，冻结的出战角色不会硬放技能。我方出战身上的附着会被敌方技能打出反应，血量偏低或手里骰子不多时，换到干净角色躲开 +2 反应或水/冰冻结会额外加分。
- **骰子利用**：骰子不跨回合保留，模型想提前结束回合但手里还有 2 颗以上骰子、且存在专家评分明显为正的出牌或攻击动作时，会改走该动作，日志 `mode` 追加 `+usedice`；换人本身就要交出行动权、不算用掉骰子，不参与这个兜底；没有划算动作时仍正常结束，避免为了花骰子做亏动作。
- **动态费用与增益**：手牌费用按卡面数字读取实际值（已包含减费），并记录本回合“少花费/费用-”“元素爆发减能”“切换角色减费”等效果；只记录脚本自己打出的牌与技能文本，装备加成按角色和槽位归属，同槽换装会覆盖旧加成，条件触发的效果不会被当成常驻加成。
- **防守与骰子预留**：按敌方出战角色可达的最高伤害（含元素爆发充能与元素反应）加上敌方结束阶段伤害估算我方出战角色的阵亡风险；有风险时优先换到能扛过本轮威胁的健康角色、提前打出治疗/护盾牌，并预留换人所需骰子——不把最后一颗骰子交给打不死人的技能或普通牌，避免骰子用光后被对手连续行动击杀。没有阵亡压力时不会换到比出战更残且没有技能收益的角色，有伤害可打时也不会用换人白送一次战斗行动。
- **低胜率放弃**：估算胜率低于阈值（默认 10%）且落后人头、或血量差达到 35% 时，自动走“右上角设置 → 放弃对局 → 确认”放弃本局；识别抖动不会误触发。
- **元素调和**：骰子不足时自动烧掉价值最低的手牌；先单击选中再拖到右侧骰子区（与出牌顺序一致），某张牌拖动失败会自动换下一张，高价值手牌会保留，宁可放弃技能。调和后会按画面重新核对骰子，骰子仍然不足且没有可调和手牌时不会强行释放技能。
- **自动重投**：保留万能骰与出战角色对应元素骰。
- **本地模型**：由本地训练的动作评分模型选择操作，输入包含阵亡风险、换人收益、结束阶段结算与手牌价值；旧版模型会按特征名自动对齐后继续使用，模型文件缺失或格式不兼容时回退内置策略。
- **对局记录**：可选把每步决策写入 `logs/duel_*.log`（JSONL），包含局面、候选动作、实际选择、打分与胜负结果；可用于导入 Python 后台增量训练模型，也可以自行解析做复盘，不影响正常使用。

## 使用说明

1. 游戏窗口需为 16:9 比例，推荐 1920×1080 窗口模式。
2. 在 BetterGI 中启动本脚本，然后进入七圣召唤对局；任意界面均可。
3. 对局结束后脚本自动退出，可在 BetterGI 中再次启动；每次出牌/调和前都会先确认是否已进入结算界面，不会在“对局胜利/失败”界面上继续操作。
4. 首次使用建议先打一局低风险对局，确认识别与点击正常。

### 对局轨迹与训练

开启 `writeTrace` 后，每局会写入 `logs/duel_YYYYMMDD.log`（JSONL，一行一条记录）。文件包含每一步的局面、候选动作、脚本最终选择、专家/模型打分，以及开局阵容与对局结果，可以直接用 `开发/` 里的 Python 管理后台导入数据集，增量训练动作评分模型；也可以自行解析做复盘分析。轨迹只保存在本地，不会上传。同样的局面和选择连续重复（点击被面板挡住、操作没有生效）时只记录第一条，`result` 里的 `skipped_steps` 是本次过滤掉的重复决策数。

`logs/` 已在 `manifest.json` 的 `saved_files` 中声明，更新脚本时会随用户数据一起备份和恢复。

### 脚本设置

| 设置项 | 说明 | 默认 |
| --- | --- | --- |
| `useModel` | 启用本地模型；关闭时使用内置专家策略 | 开启 |
| `modelFile` | 模型文件路径（相对脚本目录） | `assets/model/policy.json` |
| `actionDelayMs` | 每次键鼠操作后的额外延时；电脑较慢时可适当调大 | 200 |
| `handCountMode` | 手牌数量识别方式：自动 / 数字识别 / 模板匹配 / 关闭 | 自动 |
| `useActionCards` | 识别并打出行动牌；关闭后手牌仅用于元素调和 | 开启 |
| `scanZones` | 识别双方支援区与召唤物区 | 开启 |
| `zoneClickFallback` | 区域卡低置信度时点击查看详情 | 开启 |
| `characterStateScan` | 点击双方出战角色读取详情面板的「角色状态/阵营出战状态」 | 开启 |
| `writeTrace` | 是否把对局轨迹写入 `logs/duel_*.log`，可用于训练 | 开启 |
| `detailLog` | 输出调试日志 | 关闭 |
| `autoSurrender` | 胜率过低时自动放弃对局 | 开启 |
| `surrenderThreshold` | 放弃对局的胜率阈值（%）：0/5/10/15/20/25/30 | 10 |

## 常见问题

- **手牌显示“未知”**：悬停识别没有读到卡名。未知牌不会主动打出，但会按中等价值参与调和排序，不影响对局继续。
- **装备/圣遗物没有装上**：脚本会自动等待并点击下方“确认”按钮；若连续失败，会在本局跳过该牌。
- **某张牌打不出去**：脚本会先校验手牌数量，失败会重试；连续失败 4 次后本局不再尝试打出行动牌。
- **卡在某个界面**：先手动结束回合或关闭弹出面板，脚本会自动恢复；超过 3 分钟无法识别对局状态、或连续约三分钟（20 次决策）牌局没有任何变化，都会自动退出（后者会保存 `debug_no_progress_*.png` 现场截图）。
- **支援牌/召唤物显示未知**：新卡可能还没有对应原画模板，不影响出牌与技能决策；召唤区还会退回“点击读卡名”的兜底方式。
- **点击没反应**：在设置里把 `actionDelayMs` 调大（如 300~500）后重试。

## 已知限制

- 仅适配 16:9 的 PC 客户端 UI，其他比例或云游戏画面需要重新标定坐标与模板。
- 手牌名称依赖悬停 OCR；悬停区域或详情面板布局变化时会识别为“未知牌”。
- 需要二次选择目标的事件牌（挑选、随机选牌、交换手牌、弃牌等）会被自动跳过。
- 支援牌与召唤物都依赖原画模板匹配，尚未收录模板的新牌可能识别不到。模板按 1920×1080 局内实测单档生成（支援区 99×109、召唤区 70×83），换成其他窗口尺寸需要重新生成模板。
- 角色阵亡动画、手牌遮挡等情况下可能出现短暂误读，脚本每一步都会重新读取牌桌状态。
- 卡面费用数字模板目前只收录 0/1/2/3/5，未收录的费用（如 4、6）会沿用卡牌库静态费用；减费牌读取到卡面数字时以卡面为准。
- 增益只根据脚本自己打出的牌/技能文本推断，敌方施加且界面无法识别的负面状态（冻结除外）不会计入；带“触发后/如果/每回合”等条件的装备/支援效果不会被当成常驻加成。
- 每回合最多主动打出 2 张高价值行动牌，并为后续技能与换人预留骰子；能斩杀时不会出牌。

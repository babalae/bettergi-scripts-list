# 自动地脉花 - API 版


直接调用bettergi本体的地脉花，基于 BetterGI JsAPI,功能较少但胜在稳定

---

## ✨ 主要功能

* **全自动运行**：配置好后点击运行，自动完成地脉花刷取全流程。
* **地脉移涌智能检测**：开启"仅有双倍时刷取地脉花"后，脚本会通过 OCR 自动检测地脉移涌活动，仅在双倍产出时执行刷取
* **树脂策略配置**：支持使用脆弱树脂、须臾树脂，以及树脂耗尽模式。
* **智能队伍切换**：支持配置战斗队伍和好感队伍，自动切换。
* **自动合成浓缩树脂**：可配置前往合成台自动合成浓缩树脂。

---

## 🚀 使用方法

1. 在调度器中新建一个配置组，将脚本添加进去。
2. **右键点击**脚本，选择 **"修改 JS 脚本自定义配置"**。
3. 根据需求配置各项参数后运行。

### 📌 配置项说明

#### 必填项

* **刷取次数**

  * 设置要刷取地脉花的次数（默认 12 次）。

<br>

* **国家地区**

  * 选择要刷取地脉花的国家区域。
  * 支持：蒙德、璃月、稻妻、须弥、枫丹、纳塔、挪德卡莱、至冬（暂未更新）。
  * 默认：挪德卡莱。

<br>

* **地脉花类型**

  * 选择刷取的地脉花类型：启示之花（经验）或藏金之花（摩拉）。
  * 默认：启示之花。

#### 可选项

* **树脂耗尽模式**

  * 开启后，脚本会根据当前树脂情况自动计算刷取次数，树脂耗尽后停止。

<br>

* **耗尽模式取小值**

  * 在树脂耗尽模式下，取计算结果的最小值作为刷取次数。

<br>

* **仅有双倍时刷取地脉花**

  * **功能**：开启后，脚本会先通过 OCR 识别地脉移涌（双倍产出）活动。
  * **行为**：
    * **检测到双倍**：发送通知"识别到两倍产出"，继续执行地脉花任务。
    * **未检测到双倍**：发送通知"未识别到两倍产出"，脚本直接退出。
    * **OCR 识别失败**：发送通知"错误：OCR失败，两倍产出状态未知"，脚本退出。
  * **适用场景**：适合只想在双倍期间刷取的玩家，如果不想多刷，需要把次数定为两次，因为API没法精准设置用多少体力，只能限制次数，当限制为两次时且体力大于80，那么他就会用80体力。

<br>

* **使用冒险之证寻找地脉花**

  * 开启后，通过游戏内冒险之证功能定位地脉花位置。
  * 关闭后，改用内置路线，不通过冒险之证定位地脉花。
  * 默认：开启。

<br>

* **战斗队伍名称**

  * 输入用于战斗的队伍名称（需与游戏内完全一致），留空则不切换。

<br>

* **好感队伍名称（可选）**

  * 输入用于领取奖励的好感队伍名称，可在刷取地脉花的同时获取好感度。

<br>

* **战斗超时时间（秒）**

  * 设置战斗超时时间，超过该时间后脚本会判定战斗失败（默认 120 秒）。
  * **注意**：此值应大于或等于战斗策略中配置的超时时间。

<br>

* **前往合成台合成浓缩树脂**

  * 开启后，脚本会在需要时自动前往合成台合成浓缩树脂。

<br>

* **使用脆弱树脂**

  * 开启后，当原粹树脂不足时会使用脆弱树脂。

<br>

* **使用须臾树脂**

  * 开启后，当原粹树脂不足时会使用须臾树脂。

<br>

* **发送详细通知**

  * 开启后，脚本执行完毕会发送详细的通知信息。

// 描述：超导队：八重神子 / 奥黛塔 / 七七 / 桑多涅（八重与桑多涅必须有，角色名用官方中文名）。
//       基于 Siki 的「木偶星超导」调整的四队版。
//       副本「逆悬的冰河」实测约 20~25 秒一场；建议开启「战斗中持续索敌」，桑多涅会对着敌人攻击。
//       八重：按住 W 前进连放两次 E，松开 W 停稳（后撤步）再放第三次 E。
//       七七：开大前站住 1 秒吃自己 E 打出的冰球，否则 80 点能量的 Q 攒不满、BGI 会静默跳过。
//       桑多涅：Q 之后 check 一次，这一发常常直接收尾。
// 更新：2026-09-12
//
// 【机制速记】
//  - 每行是一个角色的一轮动作，整份脚本按行循环执行，直到战斗结束
//  - keydown/keyup 是"按住/松开"，必须成对！漏了松开，这个键会一直按到打完
//  - e/q 按下去不做成败判断，放完技能后面跟 wait 兜一下
//  - q 只有"满能量且不在 CD"时 BGI 才会真的按，没满会静默跳过（不报错）
//  - check 会站住做一次战斗结束检测（约 0.5 秒罚站），只在桑多涅 Q 之后放一个：
//    那一发常常直接收尾，早点判定结束；其它地方不放，交给 BGI 自己的检测
//  - // 是注释；换行和英文分号都能分隔语句
// =======================================================

// 八重神子：按住 W 前进连放两次 E，松开 W 停稳（后撤步）再放第三次 E
// 两下 E 之间、以及松开 W 之后各停 0.5 秒；停太短第三下 E 会被吞掉
八重神子 keydown(W),e,wait(0.5),e,keyup(W),wait(0.5),e

// 奥黛塔：E → Q → 等大招动画播完 → 补一次 E
// 她的 E 是 15 秒 CD，如果 Q 没有重置 E 的机制，第二个 e 就是空按，可以删
奥黛塔 e,wait(0.5),q,ready,e,wait(0.5)

// 七七：E 放寒病鬼差 → 站住 1 秒吃自己 E 打出的冰球 → 开 Q 回血 → 等大招动画
// 元素微粒是谁在场谁吃：站太短，球全被队友吃了；她的 Q 要 80 点能量，
// 攒不满 BGI 就静默跳过，表现就是"Q 放不出来"
七七 e,wait(1.0),q,ready

// 桑多涅：E → 普攻 → 重击 6 秒（红温特化会自动提前结束）→ E → 重击 6 秒 → E → Q → 等大招动画
// Q 后面 check 一下：这一发下去很容易直接打死，早点判定战斗结束
桑多涅 e,attack,charge(6),e,charge(6),e,q,ready,check

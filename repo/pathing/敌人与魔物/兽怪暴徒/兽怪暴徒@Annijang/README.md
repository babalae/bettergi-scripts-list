欢迎你使用由Annijang（https://github.com/Annijang）（qq是2776101087）制作的地图追踪脚本，由于本人是第一次制作脚本，有的地方可能还不熟练导致卡墙，但本人在录制完脚本后均让BGI自动运行了一遍脚本，但可能因为每个人不同的战斗策略导致出现卡墙的问题属正常情况，但如果你有多次运行之后均已发现有关地图追踪脚本的卡墙问题请联系我。
本地图追踪脚本使用[BetterG 0.63.2 Alpha.3]制作，请勿使用更低版本的BGI或者其他非BGI官方发布的版本（https://bettergi.com/）以及非正式版的BGI软件运行此脚本，否则因兼容性等导致的一切问题请联系对应版本的作者或者升级BGI版本到正式版进行解决。

测试环境：【1920x1080 窗口】、60帧

感谢空荧酒馆（https://yuanshen.site/docs/）的点位信息为我制作地图追踪脚本提供的帮助。

由于至冬地图存在迷雾灯特殊性原因，因此比较容易出现卡死等问题，请在运行本地图追踪脚本时如果遇到卡死不要慌，重新运行或者跳过特定的容易卡死的脚本即可解决这个问题。

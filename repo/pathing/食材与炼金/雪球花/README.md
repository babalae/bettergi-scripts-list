# 注意事项
- 由于线路过长且在寒冷地区，部分路线中包含克什尼克晶矿，出于采集成功率考虑，建议使用 **单手剑**、**双手剑**、**长柄武器** 角色跑图
## 跑至冬采集物之前强烈建议按照下列步骤取消掉地图上的部分影响追踪的臻冰造物
1. 按M打开地图
1. 点击屏幕下方 **臻冰造物管理** 开关
1. 随便点击一个地图上蓝色的臻冰造物
1. 屏幕右下方点击 "当前场景内臻冰造物xx" **右侧的**垃圾桶图标
1. 点击 "批量选择" **左侧的**向上箭头
1. 以下几项对地图追踪有一定影响: **第2项 "立方"、第5项 "发射台"、第9项 "标识·图案"、第10项 "标识·文字"**, 建议全部删除，如果显示 "一次性可拆除臻冰造物已达上限"，则先删除本次100个，再从第3步开始重复操作, 直到上述臻冰造物全部被删除
